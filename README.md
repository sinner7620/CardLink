# CardLink

**在 MarginNote 4 中，把摘题、查答案、整理错题和复习连在一起。**

CardLink 是一款面向题目学习的 MarginNote 4 插件。你可以为题目绑定答案脑图，也可以直接把答案放在题目下方的子卡片中，在阅读和做题时快速查看答案，再把需要巩固的题目收进错题本。

## 主要功能

### 查答案

- 支持从独立答案脑图匹配答案，或使用题目下方的直接子卡片作为答案。
- 提供标题、章节顺序和正则匹配方式，适应不同资料的整理习惯。
- 在浮动窗口中查看答案，支持图片、文字、手写内容、Markdown 和数学公式。
- 一题有多个答案时，记住上次的选择；支持定位原题或当前答案卡片。

### 做题与摘题

- 按颜色识别题目，选择章节或题目后开始做题，自动遮住子卡片答案。
- 按“标题 → 题目 → 答案”的顺序摘录，自动切换工具并整理卡片。
- 通过悬浮球快捷区进入做题、摘题和插件工作台。

### 错题整理与复习

- 随手标记错题，在工作台集中浏览、搜索和筛选。
- 用六档掌握程度记录学习进展，按到期队列安排复习。
- 在错题详情中查看题目和答案，快速返回原卡片；列表可自动隐藏，为阅读留出更多空间。
- 将选中的题目导出为 PDF 或 Markdown，可选择包含答案、来源和复习记录。

## 安装

1. 从 [GitHub Releases](https://github.com/sinner7620/CardLink/releases/latest) 或 [Gitee Releases](https://gitee.com/baidreams/CardLink/releases) 下载正式版 `.mnaddon` 文件。
2. 使用 MarginNote 4 打开文件，或在插件管理中导入并启用。
3. 完全退出并重新打开 MarginNote。

支持 MarginNote 4.0.0 及以上版本。使用悬浮球快捷区和摘题功能前，请先安装并启用 **MN Utils**。

## 开始使用

打开题目所在的脑图，在插件设置中选择答案来源：绑定另一张答案脑图，或使用题目的直接子卡片。选中题目后即可查找答案，也可以将题目标记为错题，之后在工作台统一复习。

使用子卡片做题时，先设置题目颜色，再选择章节或题目开始练习。
