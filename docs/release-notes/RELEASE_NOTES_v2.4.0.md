# CardLink v2.4.0

## 重要提醒

1. 此版本插件部分功能依赖于前置插件 MNUtils，请前往论坛下载。
2. Beta 版用户安装此次正式版更新后，需停用 Beta 版插件，以免造成数据干扰。

本版本对错题管理、复习计划、导出系统和插件窗口进行了较大规模重构。

## 新增

- 错题等级由六档重构为「不会 / 不熟 / 掌握」三档，并支持旧数据迁移。
- 新增错题收藏、复测历史、今日队列、逾期任务及恢复复习计划。
- 新增插件总开关，可独立控制卡片侧边「查找答案 / 标记错题」按钮。
- 新增重置窗口大小与位置按钮。
- 新增插件全局悬浮球，点击可进入插件，长按可重置窗口位置。
- 新增插件使用说明入口。
- 新增 PDF 导出进度、取消任务和任务状态管理。
- 新增 PDF 每页题目密度、答案位置和复习历史详细程度设置。
- 新增大数据 Bridge 分块传输，提高大量错题及复杂卡片处理稳定性。

## 优化

- 重构错题浏览和详情界面，增加搜索、标签、来源、收藏、时间和等级筛选。
- 优化大规模错题加载，增加 revision 与分页数据传输。
- 插件 WebView 提前加载，减少首次打开时重复请求和白屏等待。
- 跨学习集定位原题后不再无意义刷新整个错题数据。
- 调整工具栏状态刷新逻辑，使按钮选中状态与插件窗口保持一致。

## 修复

- 修复插件窗口拖至屏幕顶部后出现白条、顶栏偏移的问题。
- 修复在卡片旁标注错题、更改错题等级后不会减少待复习题数量的问题。
- 修复选中卡片或切换脑图时插件窗口尺寸、位置异常变化的问题。
- 修复跨脑图切换过程中插件窗口尺寸逐渐增长的问题。
- 修复插件启动异常时一直显示空白界面的问题。
- 修复插件工具栏图标状态与实际窗口状态不一致的问题。

## 兼容与数据影响

- 正式版继续使用既有正式插件 ID，可覆盖安装并保留原有配置、答案绑定、错题和复习数据。
- 旧版六档错题等级会迁移至新版三档等级；迁移后保留错题记录与复测历史。
- Beta 版与正式版为不同插件实例；升级后需停用 Beta 版，避免重复按钮或数据相互干扰。
- 部分功能需要另行安装 MNUtils 前置插件。
