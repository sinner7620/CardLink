# CardLink 2.4.8 更新说明
摘题skill已发布，可在论坛或插件发布页下载。

## 新增与更新
- 快速链接：在错题本列表长按错题，可拖到当前学习集的脑图卡片，为目标卡片添加原题链接。已链接题目卡片的会在错题详情显示，点击即可直接跳转链接的题目。
- 答案预览内批注：在设置内开启后，打开独立答案窗口，展开右上角工具条即可用Pencil 批注。

## 修复与优化
- 修复待复习徽标与实际题目数不一致的问题。
- 取消点击搜索框后触发的全库扫描，减少卡顿。
- 错题本和待复习页记住筛选与排序。
- 优化匹配多张同名答案的筛选机制，现在筛选没有结果，则显示全部同名候选。
- 改善定期 OCR 触发机制。
