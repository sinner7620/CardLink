# CardLink v2.4.5

## 新增与改进

- 做题模式支持答案脑图。
- 安装更新现可以直接安装。

## 修复与性能

- 优化普通子脑图卡片读取、指定子树索引重建和顺序匹配，减少重复展开及不必要的全学习集遍历；索引异常时提供刷新、换绑入口及绑定信息。
- 错题详情先读取原题，按需加载并复用答案；快速切题时防止旧请求覆盖当前详情。
- 修复混合绑定中原题预览误带子卡答案，取消批量标记的选卡过滤；逐卡保存批量成功项，单卡失败不丢失其他成功记录。
- 修复 Markdown 标题评论被当作标签隐藏、Safari 混合手势重复缩放、复习控件重新挂载后可能空白及反馈后列表刷新不及时等问题。
- 调整错题列表滚动、自动隐藏列表、长标签和原卡缺失提示，改善窗口及悬浮菜单交互。
