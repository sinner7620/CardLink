CardLink 2.4.7 更新说明
新增与更新
- 错题 OCR 与搜索：在「设置 → 错题管理」新增错题 OCR 数据库。建立OCR数据库后可在错题本搜索框内搜索题干。（原 AI 错题分析与报告入口暂时移除。）
- 指定答案脑图后，题目脑图默认全部卡片为题目，无需再绑定颜色。子卡片和混合模式继续使用颜色筛选。
- 插件自动判别MarginNote 的传统或场景界面，无需手动开启场景功能。MN5 场景中可按当前笔盒里的工具名称绑定摘题步骤，传统界面仍在选笔后确认。
- 新增插件缓存扫描功能：「设置 → 关于插件 → 缓存清理」可扫描本地占用，选中的文件经确认后移入 CardLink 回收站。实际文件仍需要手动在「文件」App 中删除。
- 错题导出新增是否包含脑图绑定书写和子评论的选项。
- 新增框选做题，在脑图中选择多张卡片后可直接在插件悬浮球内开始做题，
优化与修复
- 修复题目卡片颜色绑定失败的问题
- 修复场景模式下摘录工具无法绑定以及切换异常的问题。（注意更改工具位置后需要重新绑定。）
- 修复使用批注模式做题/复习时模版配置检测失败的问题。
- 修复包括错题详情页面等多处脑图节点显示顺序反序的问题。
- 修复传统模式下，导出页面筛选项无法点击的问题。
- 修复错因标签在插件内无法显示的问题。
- 优化错题本的筛选和搜索功能，并加入了排序。
- 修复错题导出答案数量匹配数量异常及导出卡死的问题。
- 优化在匹配答案时，根据父节点异同减少同名无关答案。
- 优化PDF准备过程，改为逐题准备和分页，按实际页数显示生成进度，并改进取消和错误提示。长图可连续跨页，标题随首段排版，叠加笔迹随底图缩放和裁切。
- 优化导出文件横向题图和公式截图的缩放算法，减少短题或大字题图撑满页面的情况。
- 优化更新界面。
