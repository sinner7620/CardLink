## 变更目的

将仍在使用旧项目名的活跃品牌、仓库、包与发行标识统一为 `CardLink`，同时保持正式插件 ID 不变。本轮经用户确认覆盖 `2.4.0`，不迭代版本号。

- GitHub 仓库由 `sinner7620/mn4_answer_matcher` 重命名为 `sinner7620/CardLink`，本地 `origin` 同步更新。
- npm 工作区包名改为小写技术标识 `cardlink`；用户可见品牌保持规范写法 `CardLink`。
- 构建目录、`.mnaddon` 文件名、本地完整界面预览文件、GitHub Actions 工作流/发行资产、Gitee 同步脚本统一使用 `CardLink`。
- README、代码文档、本地预览、官网 GitHub 链接和更新请求 User-Agent 同步统一。
- 更新器优先匹配 `CardLink-v<版本>.mnaddon`，并保留历史 `mn4-answer-matcher-v<版本>.mnaddon` 的只读兼容匹配，避免旧 Release 资产不可下载。
- 本地仓库的逻辑名称、包名与远程仓库已统一；物理工作目录拟由 `E:\project\MN` 重命名为 `E:\project\CardLink`，但当前 Codex 会话持有目录文件锁，Windows 拒绝了原位重命名，源目录未发生变化。

## 保留的兼容标识

- 正式插件 ID：`marginnote.extension.mn4-answer-matcher`。
- 以该 ID 或旧内部前缀命名的设置、错题、绑定、索引、窗口位置、遥测和迁移确认存储键。
- 历史发布说明中记录的旧安装包文件名，以及官网仍提供下载的历史版本文件。

这些标识若直接改名会切断已安装用户的数据与升级连续性，因此不属于显示名称统一范围。
