# CardLink 2.4.1 正式版发布

## 变更目的

将已完成验证的 `2.4.1b11` 转为正式版本 `2.4.1`，并按本轮发布口径整理用户可见更新说明。

## 已实现行为

- `package.json` 版本由 `2.4.1b11` 更新为正式版 `2.4.1`。
- 新增正式版 `RELEASE_NOTES_v2.4.1.md`，说明脑图绑定手写合并至 OCR 图片、CardLink 缓存与目录迁移、MinerU 轮询/结果回对/Markdown 读取修复，以及待复习批量展开卡住问题修复。
- 发布说明补充已确认的已知问题：插件在软件内显示“未认证”属于 MarginNote 软件端问题，需等待后续软件更新。
- 修复 Gitee Release 同步脚本缺少 API URL 构造函数的问题，确保标签工作流可创建 Gitee Release 并上传安装包。
- 插件 ID、标题和 `mnChannel: "stable"` 保持不变。

## 影响文件与模块

- `package.json`：正式版本号。
- `RELEASE_NOTES_v2.4.1.md`：正式版更新说明。
- `scripts/sync-gitee-release-notes.mjs`：Gitee Release 发布同步。
- `docs/changes/2026-09-11-2.4.1-formal-release.md`：本轮发布记录。

## 兼容与数据影响

- 本轮只进行正式版本标记和发布说明汇总，不新增业务逻辑或数据结构变化。
- 正式包沿用 b11 已验证的实现与数据兼容策略。
