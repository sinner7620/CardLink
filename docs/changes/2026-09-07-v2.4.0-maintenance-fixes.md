# v2.4.0 maintenance fixes

## Purpose

- Apply the user-confirmed maintenance exception that permits this round to overwrite the existing `2.4.0` artifact without iterating the version.
- Track the requested compact mistake-list controls, `CardLink` display name, legacy mistake-tag rewrite, AI settings redesign, and MinerU OCR progress repair.

## Implemented behavior

- Updated the repository working agreement so an explicitly user-confirmed round may keep the current version. The exception is scoped to the confirmed round and still requires release notes, validation, rebuild, delivery replacement, and SHA-256 recording.
- Centered the native batch-level select label and standardized all three mistake-list floating-header rows to 28px controls with tighter row spacing.
- Renamed the installed and runtime plugin display title to `CardLink` while keeping the stable plugin identity and version `2.4.0`.
- Changed mistake-index repair so legacy managed tags are rewritten in place to `错题_不会` / `错题_不熟` / `错题_掌握`; ordinary user tags remain intact and answer-only scopes remain untouched.
- Reworked the AI settings page into a single export-style composer with a clear page heading, numbered groups, hairline separation, progressive editors, responsive layout, and accessibility media-query fallbacks.
- Added MinerU OCR stage details and monotonic progress across upload-address creation, each image upload, parse polling, and result download. Presigned uploads explicitly use an empty `Content-Type` for OSS signature compatibility.
- Updated the migration consent copy so the on-card tag rewrite and level mapping are disclosed before acceptance.
