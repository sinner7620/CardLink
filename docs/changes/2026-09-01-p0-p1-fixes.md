# 2026-09-01 P0/P1 修复记录

## 目标

根据 `beta.54` 交接问题、真机反馈和 UI 层级评审，完成 P0/P1 修复，并保留 Beta 与正式版共享错题数据的现有机制。

## P0 修复

### 裸标签不再被插件接管

- `不会`、`不熟`、`掌握` 三个裸标签始终视为用户自定义标签。
- 它们不再用于恢复错题身份，也不会在取消错题时被插件删除。
- 插件只管理具有明确命名空间的错题等级标签。

涉及模块：`src/mistake-tags.ts`、`tests/domain.test.ts`。

### 正式版与 Beta 版共存提醒

- 继续允许正式版和 Beta 版读取同一份共享存储，不拆分数据目录或存储键。
- 正式版首次启动时显示明确提醒：正式版不能与 Beta 版同时启用，应关闭或卸载 Beta 版后再使用正式版。
- Beta 构建不显示该正式版提示；提示使用独立的一次性标记，避免每次启动重复打扰。

涉及模块：`src/plugin.ts`、`tests/plugin-events.test.ts`。

### 写入结果必须可验证

- 错题标签写入改为 `verified`、`unverified`、`failed` 三态结果。
- 写入后无法回读时不再乐观提交本地错题状态。
- 批量操作只撤销写入失败的学习集，成功项仍可正常保存。

涉及模块：`src/mistake-manager.ts`、`tests/mistake-write-behavior.test.ts`。

## P1 数据与交互修复

### 收藏按记录 ID 持久化

- 收藏状态改为写入错题记录，以 `recordId` 区分同名题目。
- 旧版按标题保存的收藏只在标题唯一时迁移，避免同名题互相串联。
- 收藏按钮由 React 直接渲染，不再依赖 MutationObserver 注入业务状态。

涉及模块：`src/mistake-domain.ts`、`src/mistake-manager.ts`、`src/rails-core.ts`、`web/src/main.jsx`、`web/src/preview-favorites.js`。

### 列表、日期与统计口径统一

- 最近 7 天和最近 30 天改为自然日口径。
- 列表数量以当前过滤结果为准。
- 来源分类持续显示，不再被用户标签覆盖。
- 紧凑列表压缩为三行结构，移除低价值的新增日期行，并统一等级胶囊尺寸。

涉及模块：`src/mistake-manager.ts`、`web/src/main.jsx`、`web/src/panel.css`。

### 答案索引刷新入口

- 索引快照成功写入后记录更新时间。
- 未找到答案时展示索引更新时间，并提供“刷新索引后重试”入口。
- 刷新完成后自动重试一次当前答案查询。

涉及模块：`src/index-store.ts`、`src/matcher.ts`、`src/plugin.ts`。

### 错题存储可靠性与性能

- 工作台日常读取直接使用持久化快照，不再逐条扫描 MarginNote 卡片。
- 标签反向恢复只在显式刷新或修复时执行，避免普通面板刷新触发全量扫描。
- 单条复习和分类修改先提交卡片标签，再一次性保存状态。
- 备份扩展为当前备份加两级轮换，并限制高频备份写入。
- 记录来源卡片是否仍可访问，显式修复时更新该状态。

涉及模块：`src/mistake-manager.ts`、`src/mistake-store.ts`、`tests/mistake-performance.test.ts`。

### 原题定位与 MN Utils 入口

- 定位原题先派发 MarginNote 官方聚焦指令，再进行同步状态探测。
- 同步模式不满足要求时提示：检查脑图文档同步模式是否为“双向同步”或“从文档定位到脑图”。
- 跨学习集定位提示通过会话接力保存，在学习集切换后仍能显示。
- 每道题目的定位成功动画按 `recordId` 隔离，避免其他题目同时变成成功状态。
- MN Utils 长按入口改用公开的静态调用签名 `MNButton.addLongPressGesture(button, target, selector, duration)`，并只响应长按开始状态。
- 非脑图场景不执行入口点击行为，长按后抑制紧随其后的误点击。

涉及模块：`src/note-navigation.ts`、`src/mnutils-entrance.ts`、`src/globals.d.ts`、`web/src/main.jsx`。

### 窗口与重复标记语义

- 恢复插件窗口位置时将保存 frame 约束到当前学习窗口可见范围。
- 已是错题的卡片再次打开标记菜单时，标题显示为“复习结果”；新题仍显示“标记错题”。

涉及模块：`rails-native/WebPanelController.js`、`src/floating-toolbar.ts`、`src/plugin.ts`。

## P1 UI 精简

- 总览进度、批量确认状态、时间线和收藏状态迁入 React 数据流，减少 DOM 后处理。
- 时间线使用真实复习间隔，支持横向滚动，并采用方形内部连接端点。
- 导出页合并为一个主面板，用标题、间距和分隔线组织筛选、内容、格式与文件设置。
- 普通区域移除多余的灰底子卡片、边框、圆角和阴影；保留格式选择、重要状态和预览结果等有独立语义的卡片。
- 导航角标改为文字发光，不再对整个角标盒子加光晕。
- 迁移弹窗提高层级，避免被其他面板覆盖；退出调试模式时清除旧联通测试结果。

涉及模块：`web/src/main.jsx`、`web/src/panel.css`、`web/src/panel-preview.css`、`web/src/ui-alignment.js`、`web/src/ui-redesign.js`。

## 兼容性与数据影响

- 正式版和 Beta 版继续共享存储，未执行数据拆分或破坏性迁移。
- 新收藏字段兼容旧记录；旧标题收藏采用保守的一次性迁移策略。
- 旧错题记录仍可读取；新增的来源可用状态和索引更新时间均为可选信息。
- 本轮没有删除或重置用户错题数据。
