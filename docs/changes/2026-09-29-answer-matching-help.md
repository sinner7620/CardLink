# 答案匹配方式说明入口

## 目的与实现

按用户要求，在答案绑定管理的“答案匹配方式”列标题后添加说明图标，点击弹出易懂的说明，供用户继续修改文案。

- `web/src/main.jsx`：复用现有 info 图标，新增只读说明弹窗，介绍答案脑图、直接子卡片、题目颜色要求及做题遮盖。按用户定稿移除“怎么选？”与混合查找说明。移除标题容器的 `aria-hidden`，使说明按钮可被辅助技术访问。
- `web/src/ui/settings.css`：添加紧凑图标按钮与适应窄窗口的弹窗样式。使用浏览器模态 dialog 管理焦点，支持“知道了”和 Esc 关闭并返回入口。
- `docs/pages/settings.md`：补充说明入口与关闭方式。

## 兼容与数据影响

仅添加 Web 界面说明，不修改答案匹配逻辑、绑定数据或原生桥命令。用户明确授权本轮同版本覆盖生成 2.4.4，保留 stable 通道及正式插件身份；此例外仅适用于本次交付。
