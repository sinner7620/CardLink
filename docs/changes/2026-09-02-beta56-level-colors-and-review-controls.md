# beta.56 三档色板与待复习控件一致性

日期：2026-09-02  
版本：2.3.3-beta.56

## 目的

修复总览进度条与下方三档色点颜色不一致、原生侧边卡片三档按钮仍使用旧色板，以及待复习三档结果按钮比左侧操作按钮更高的问题。

## 已实现

- `src/ui-tokens.ts` 中三档唯一语义色调整为：不会 `#ff453a`、不熟 `#ff9f0a`、掌握 `#30d158`。
- 总览进度条与下方图例均读取 `--mn-level-0/1/2`，不再分别维护硬编码颜色。
- 原生侧边卡片下拉按钮继续读取 `UI_COLORS.level0/1/2`，因此与 Web 进度条和图例同步更新，不新增独立样式或关闭/刷新逻辑。
- 待复习三档结果按钮高度由冲突的 `42px` 收口为 `31px`，与左侧“定位原题 / 查看答案 / 复测历史”按钮一致；三档仍在换行时等分铺满一行。
- 增加自动化约束，防止色板再次分叉或 `42px` 旧尺寸回流。

## 影响范围

- `src/ui-tokens.ts`
- `src/floating-toolbar.ts`（继续复用统一 token，无新增实现）
- `web/src/ui/controls.css`
- `web/src/ui/review.css`
- `tests/web-bridge.test.ts`
- `RELEASE_NOTES_v2.3.3-beta.56.md`

## 兼容性与数据影响

- 仅调整视觉 token 与按钮尺寸，不变更错题数据、复习计划、共享存储或桥接协议。
- beta.56 版本号保持不变，本次修复并入同一 beta.56 安装包。
