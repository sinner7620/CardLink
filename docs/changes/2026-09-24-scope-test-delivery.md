# 安装包交付取消固定完整测试命令

## 目的

按用户要求取消每次打包和发布时固定运行完整 `pnpm test` 命令，改为依据改动范围选择相关行为测试。

## 规则变更

- `AGENTS.md`、`docs/workflow.md`：安装包交付仍需对最终输入运行 `pnpm check`、相关行为测试与 `pnpm build`，并核对版本、插件身份及交付哈希；`pnpm test` 保留为按需手动运行的完整回归命令。
- `.github/workflows/release.yml`：去除发布流水线的固定 `pnpm test` 步骤，保留安装依赖、类型检查、构建、版本标签核对和发布步骤。
- 此更改只影响验证流程，不改动插件代码、数据、版本或已交付的 `2.4.4-b1` 包；该包的历史实际验证记录保持原样。

## 验证与限制

- 已核对文档与 CI 配置的一致性、相对链接和 `git diff --check`；文档/工作流变更未运行应用测试或构建。
- 后续交付需在任务记录中写明选了哪些相关行为测试及其结果；缺少 MarginNote 真机测试时继续单独说明。
