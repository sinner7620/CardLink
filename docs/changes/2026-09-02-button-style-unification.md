# 错题页按钮样式统一

## 目的

统一错题多选工具栏和详情工具栏的次级按钮视觉，消除同一区域内导出、题目/答案与“定位原题”使用三套外观的问题。

## 已实现行为

- 删除批量“导出”按钮独有的主蓝实心覆盖；它继续复用 `controls.css` 中已与“定位原题”、详情折叠、标签等控件共用的次级按钮规则。
- 详情“题目/答案”未选中态改回 `--preview-ui-button / --preview-ui-line`，与“定位原题”使用相同底色和边框 token。
- 选中的题目或答案仍使用现有蓝色选中态；取消错题仍保留危险操作样式。
- 未新增按钮 class、颜色值或独立样式体系。

## 影响文件

- `web/src/ui/mistakes.css`
- `tests/web-bridge.test.ts`
- `RELEASE_NOTES_v2.3.3-beta.54.md`

## 兼容性与数据影响

仅调整 CSS 级联结果，不修改 DOM、桥接命令、错题数据或导出行为。

## 验证

- 自动化测试确认批量导出仍由公共次级按钮规则拥有，页面模块不再存在主蓝覆盖。
- 自动化测试确认题目/答案未选中态直接使用与定位按钮一致的现有 token。
- `pnpm check`、全量测试 155/155 和生产构建通过。
- Playwright 检查批量工具栏与详情页的启用、禁用及选中状态。

## 未验证限制

WKWebView 的原生字体抗锯齿与浏览器略有差异，最终触控观感仍建议在 MarginNote 4 真机确认。
