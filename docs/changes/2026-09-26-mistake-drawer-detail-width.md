# 错题列表拉出时详情横向调整宽度

## 目的

列表以自动隐藏方式从左侧拉出时，详情应始终填满列表右侧的剩余区域，不应整体等比缩小。

## 实现

- 用列表露出的像素宽度共同驱动列表平移和详情容器的实际宽度；详情右边缘保持贴合工作区右侧。
- 移除详情整体缩放和额外左内边距，预览内容随可用宽度重新排布。保留原有点击、拖动、反向拖动及缓动落位方式。
- 更新错题本功能说明。涉及 `web/src/MistakeLayout.jsx`、`web/src/ui/mistake-drawer.css` 和 `docs/pages/browse.md`。错题数据与设置格式不变；本轮未交付安装包。

## 验证与限制

- `pnpm check`、Web 渲染测试 11 项和 `pnpm build` 通过；构建保留已有 `.sfIconGlyph:svg` CSS 告警。
- 本地浏览器预览在 1280px 与 700px 宽度检查了列表展开和收起。详情一直铺满列表右侧剩余区域，标题、正文和操作条保持正常字号，收起后占满工作区。
- 在 700px 窗口从列表内拖动约 100px 时，列表右边缘与详情左边缘同步停在约 240px，松手后回到展开位置。MarginNote 设备未连接，原生窗口中的拖动手感尚未验证。
