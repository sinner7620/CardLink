# 2026-09-07 — AI 配置页真机触摸滚动与旧标签优先级回归（v2.4.0 同版本覆盖）

## 变更目的

修复 AI 配置页在 MarginNote 触摸环境中无法滑动的问题，并再次验证 beta.2 卡片常见的 `#错题 + #错题X级` 双标签不会被错误迁移为“不会”。本轮经用户确认覆盖 `2.4.0`，不迭代版本号。

## 实现行为

- 将根节点 `html/body` 的 `touch-action` 从 `none` 改为 `pan-x pan-y`。根布局仍由 `overflow:hidden` 锁定，不产生根滚动；AI 配置页继续以 `overflow:auto + touch-action:pan-y` 持有纵向滚动。
- 真浏览器运行时进一步发现 AI 页为 Grid 容器，而内容面板使用 `overflow:hidden`；Grid 自动行因此可被压缩至视口剩余高度，下半内容被面板裁剪，外层实测 `clientHeight` 与 `scrollHeight` 都是 760px，实际上没有滚动范围。AI 页现改为 `grid-auto-rows:max-content; align-content:start`，内容面板按完整内容高度参与外层滚动。
- 扩充旧标签写入测试，让 0、3、5 级样本都使用 beta.2 的双标签结构。迁移解析先读取具体等级标签，独立 `#错题` 只负责确认错题身份；仅在完全没有等级标签时才回退到“不会”。
