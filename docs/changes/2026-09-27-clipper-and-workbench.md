# 摘题模式整合与工作台交互调整

## 目的与参考

完成本轮快捷区、题目子卡片、摘题设置、错题列表、待复习与设置分类的修改清单。
参考用户提供的 `QuestionClipper-v0.4.1-beta.1-source.zip`，以及同步文件夹中的 `方案切换组件-demo.html`。

## 实现

- 快捷区关闭符号由 28 点粗体调整为 26 点常规字形。
- 按颜色收集题目时排除题目后代，子卡片即使颜色相同也不加入题目数量和做题队列。
- 仅当当前题目采用子卡答案、颜色符合配置且没有独立绑定答案脑图时，原题 HTML 不包含子卡片；混合模式适用相同规则，有独立答案脑图则保留子卡。默认卡片渲染行为不变。
- 答案配置新增「摘题」分组：打开摘题模式、展开摘题设置。设置可记录三个步骤当前选中的 MarginNote 工具；答案位置为子卡片；标题摘录默认开启、可关闭。
- 摘题快捷区复用原入口、布局边界与动画，主按钮展开为暂停／继续及结束子胶囊，进度显示标题、题目、答案，下方显示当前题目、母卡绑定／解除、完成数及错误提示。摘录文档与选母卡不会因点到快捷区外而收起面板。
- 进入模式关闭插件页面并暂时停用侧边按钮；点击开始后才消费 `ProcessNewExcerpt`。暂停保留步骤，结束或关闭快捷区恢复做题界面并开启侧边按钮。关闭学习集、场景和卸载时退出模式。异步回调以会话、步骤与代次隔离，重复通知不重复挂载。
- 标题摘录转换为题目标题，在题目保存后删除临时标题卡；题目挂在母卡下，答案挂在题目下。禁止跨学习集及循环挂载，失败显示提示。结束未完成流程时保留已创建卡片。
- 自动隐藏列表移除阻挡详情的透明遮罩；详情点击正常执行并收起列表，iframe 内点击也能触发收起。列表横向拖动超过阈值后捕获指针，保留普通点击目标。详情工具栏取消位置坐标的第二层动画。
- 随机补充按钮紧跟提示文字；复习入口选中阴影不在导航边界截断并降低强度；恢复展开与复习模式按钮的底色、边框与按压反馈。
- 卡片绑定手写显示、错题本列表显示方式移到「操作与窗口」。
