# 2026-09-02 UI 阶段二与阶段四重构

> 后续补记：beta.55 仅完成阶段二的首轮机械清理，仍保留 1343 处 `!important`，不能视为完整阶段二。上下半程的最终收口见 beta.59 变更记录。

版本：`2.3.3-beta.55`

## 目标

- 完成阶段二：在 `web/src/ui/` 页面所有权模块内部去重，清除无现役 DOM 的 UI 规则，保持当前可见控件不变。
- 完成阶段四：让 React 独占面板 DOM，删除生产路径上的 UI 补丁层、旧预览实现和未启用 UI。
- 按“大更改必须升版”的新约定，从 beta.54 升至 beta.55。

## 实现

### React 接管历史补丁能力

- 删除 `web/src/ui-redesign.js`、`web/src/ui-alignment.js`、`web/src/preview-bootstrap.js`。
- `data-level` 继续由 JSX 渲染，不再扫描按钮文本。
- 设置页非编辑态的复习天数摘要由 `MistakeLevelGuide` 条件渲染；编辑态只挂载可编辑输入框。
- 待复习三档按钮在 650px 以下由 CSS 自动铺满整行，不再使用全局 ResizeObserver 修改 class。
- Phosphor 方框/勾选路径进入 MorphIcon 数据源，批量选择、全选、列表勾选和脑图多选不再通过 `insertAdjacentHTML` 替换 React 图标。

### 样式阶段二

- 新增 `scripts/dedupe-ui-css.mjs`，使用 PostCSS 对八个 UI 所有权模块执行可重复的精确清理。
- 删除 160 个确认无现役 DOM 的选择器、9 条完全重复声明和约 750 行 CSS。
- 清理范围包括：旧 4–6 档等级、旧等级弹窗、玻璃实验控件、旧导出布局、旧日期/收藏/批量补丁、旧详情控件和旧预览纸张。
- `!important` 数量从本轮开始前 1401 降至 1343；剩余声明仍服务现有跨尺寸级联，不以视觉回归为代价机械删除。

### 历史 UI 产物

- 删除已跟踪但从未参与构建的 `scripts/preview-archive/` 12 个历史 UI 文件。
- 本地忽略目录 `heart-glow-demo/`、`web/export-demo/`、`src-docs/` 已移入 Windows 回收站，可在需要时恢复。
- 删除退役模块文档并更新 `docs/README.md`、`docs/boundaries.md`、`docs/modules/web/main.md` 和 `docs/modules/web/ui-styles.md`。
