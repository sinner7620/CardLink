# 做题首题聚焦与待复习悬浮筛选

## 目的

放大快捷区关闭符号，使开始做题的第一题采用复习模式的定位并聚焦方式，并消除待复习页重复的四张统计卡。

## 实现

- 快捷区 44 点关闭按钮中的符号改为 28 点粗体字形，保持原按钮热区和关闭动作。
- 同脑图做题按队列显示顺序取第一题，调用复习模式共用的焦点定位入口；焦点脑图重建后再选中该题并校准遮盖 Canvas。焦点定位失败时提示启动失败。
- 待复习页移除顶部四张统计卡。四个状态入口保留数量，与筛选图标同处一行悬浮胶囊；点击图标展开分类、等级筛选面板。宽度和顶部位置与设置页悬浮导航一致。状态滑块与参考 HTML 使用相同的 `transform .45s cubic-bezier(.32,.72,0,1)`，文字颜色使用 `.28s ease .06s`；移除按钮自身选中背景和原先的短促颜色过渡。

## 影响与兼容

涉及 `src/mnutils-entrance.ts`、`src/same-map-practice.ts`、`web/src/main.jsx`、`web/src/icons.jsx`、`web/src/ui/review.css`、`web/src/a11y.css`、相关行为测试，以及工具栏和待复习功能文档。未改变错题记录、绑定或设置数据格式。未交付新安装包，产品版本未变。
