# 发布说明归入 docs

## 目的与实现

按用户要求，将正式版发布说明放入 docs，并盘点当前 Git 跟踪文件。

- 将 Git 中六份正式版说明迁移到 docs/release-notes/，正文保持不变。2.4.3 根目录文件此前在本机已缺失，本轮从 HEAD 读取原文迁移至新位置。
- 更新 GitHub Release 工作流、Gitee 同步脚本默认路径、文档导航及维护规则。
- 根目录不再接纳 Release Notes；旧预发布忽略规则跟随迁至 docs/release-notes/，未来版本说明仍可提交。
- 使用 git ls-files 盘点全部跟踪路径，区分插件代码、测试/工具和文档/配置；完整清单输出至被忽略的 output/git-tracked-files.md。

## 验证与限制

- 核对六份说明与 HEAD 原路径内容一致；检查两端发布配置及 Gitee 默认路径均指向新目录，脚本语法及差异空白检查通过。
- 核对源码仍可跟踪，workers 与构建产物未被跟踪；仅提交本任务路径，保留 build.mjs 的既存本地删除状态及无关未跟踪记录。
- 不修改产品代码、版本、公开 Release 正文或安装包；未触发远端发布、应用测试、构建或真机验证。
