# 取消安装包交付哈希验证

## 目的

按用户要求取消每次插件安装包交付时的哈希比对与记录。

## 规则变更

- `AGENTS.md` 和 `docs/workflow.md` 不再要求比较 dist 原件与同步文件夹副本的 SHA-256；明确记录源文件和交付位置即可。
- 同版本替换流程也不再要求更新哈希记录。保留包内版本与插件身份核对，以及原有范围内的检查、构建和复制步骤。
- 已交付 `2.4.4-b1`、`2.4.4-b2` 的历史哈希记录保留，表示当时实际执行过的检查；本次没有修改安装包、版本或数据。

## 验证与限制

- 已核对两处当前规则与本记录的一致性；本次只修改文档，按文档流程检查链接、格式和差异，不运行应用测试或构建。
