# v2.3.3 正式版同步与界面修复

## 目的

将 beta 当前工作树同步到正式版项目，并补齐同步文件夹中更新至 beta.73 的列表结构改动；从布局、原生容器和状态管理的源头修复错题本、待复习和插件面板问题。

## 已实现行为

- 正式渠道：版本改为 `2.3.3`，构建产物使用正式插件 ID 与标题；原生关闭按钮位置设置键不再包含 beta 标识。
- 原生面板：拖动全程限制在宿主边界内，结束时重新锁定根滚动；禁用自动 content inset 调整；在原生容器层恢复四周柔和阴影。
- 错题工作区：列表滚动面贯通剩余高度，列表项与详情分割线采用内缩留白；悬浮筛选条使用半透明毛玻璃；搜索框降低高度并居中；等级筛选与批量改级移除原生外观。
- 列表结构：以 beta.73 最终包为依据恢复侧栏统一滚动容器与吸顶筛选栏，避免工具栏和题目列表分属两个滚动区域。
- 错题详情：纵向状态胶囊拥有稳定的 65px 高度；标签触发栏不再把标签压缩到单字；预览工具条改为 50% 背景透明度与 1px 模糊。
- 待复习：三枚左侧操作与三档结果始终同排，三档按钮固定宽度；按容器宽度依次隐藏历史、答案、定位文字。普通顶部导航会清空定向跳转 ID。
- 定位：待复习目标不再使用 `content-visibility` 估算高度，按真实可见区域两帧校正并夹取合法滚动范围。
- 交互：补齐未声明专用语义的 Web 控件统一 hover 基线，并修正详情工具条旧类名选择器。

## 影响文件与模块

- `rails-native/WebPanelController.js`、`src/window-controls.ts`
- `web/src/main.jsx`、`web/src/ui/*.css`、`web/src/a11y.css`
- `package.json`、`README.md`、正式版发布说明及相关测试

## 兼容性与数据影响

- 错题、复习历史和答案绑定的数据结构不变。
- 正式版使用正式插件 ID；首次启用仍会提示关闭旧 Beta，避免两套插件同时处理同一数据。
- 面板关闭按钮位置改用正式设置键，旧 Beta 的该项界面偏好不会覆盖正式版。
