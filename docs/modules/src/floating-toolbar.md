# floating-toolbar.ts — 悬浮工具栏
## 职责
卡片侧悬浮工具栏（查找答案/标记错题）与等级下拉；颜色来自 ui-tokens 语义色（P2-4）；定位避开屏幕边缘。

`cardMistakeAnchor` 为卡片命令侧边反馈页提供目标矩形：仅使用同 ID 的宿主卡片菜单矩形，或同 ID 原生选中视图的坐标转换。未找到目标时返回无锚点，不以其他卡片或插件面板位置兜底。反馈页由 `card-mistake-panel.ts` 管理，点击等级立即保存，不会／不熟共用按需展开的可选错因区，掌握整行；错因补写不重复计复测，外部点击关闭保留已保存等级。原侧边按钮的三级下拉保留，选择等级暂时不弹错因窗，只写等级并保留旧错因。详见[悬浮工具栏](../../pages/toolbar.md#卡片命令标错侧边页)。

## 验收
两按钮配色与面板语义一致；等级下拉三色与面板等级徽章一致。
