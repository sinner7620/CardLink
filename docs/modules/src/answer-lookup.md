# answer-lookup.md — 答案查找编排
## 职责
findAnswersForQuestion：绑定目标 → 索引/正则/顺序配对多策略。

查找答案缺少绑定时显示“尚未绑定答案”，仅提供“立即绑定”及一个系统取消按钮。确认后选择“绑定答案脑图”或“绑定子卡片”，任一步取消均不修改绑定。两条路径沿用本次查找解析出的原题学习集与题目节点，避免从错题入口操作时绑定到当前展示页面。设置页的绑定入口复用同一来源选择器。

子卡模式读取题目直接子节点；只有题目颜色在该绑定的 `questionColors` 内才参与。混合模式将直接子卡候选排在现有答案脑图匹配结果前，指定子卡模式不读取答案脑图索引。

原生查找答案窗口通过 `answer-preference.ts` 按来源学习集和原题 noteId 保存当前候选的学习集、noteId 与节点 id。成功显示候选即保存，关闭窗口或切换题目前已持久化；下次查找优先展示仍在当前匹配集合中的已选答案。节点变化时按同一答案卡恢复，卡片不再匹配时回退首项。所有去重候选保留既有顺序及序号，即使存在唯一高分或标准答案也可切换。异步候选选择返回时核对窗口和题目上下文，避免旧弹窗覆盖新题。此记忆控制原生答案窗口，不改变错题导出、AI 内容读取及网页详情候选排序。
