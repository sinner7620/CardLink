# mistake-export.ts — 错题导出

## 职责
PDF 与 Markdown：选题、素材暂存、内容组装、快速预览、取消与准备进度。

## 契约
- PDF 在题目片段加载时读取图片像素尺寸，以 96 像素/英寸换算印刷尺寸。图片超出当前栏宽或横向及方形图片超出正文区四分之一高度时逐张等比缩小，纵向长图保持栏宽比例跨页，摘录底图和手写叠加用同一裁剪窗口。脑图绑定书写维持独立尺寸。Markdown 从 PNG/JPEG/GIF 图片头读取宽度，整批使用一次倍率（自动列宽约 422px、固定布局约 703px），输出带 width 的 HTML img，资产仍为原始图片；无法读出宽度的格式保留原显示。Markdown 阅读器需支持内嵌 HTML 宽度才能呈现该版式。
- `include.handwriting`、`include.comments` 默认 false，仅显式 true 启用。书写控制摘录叠加笔迹、独立手写和题目/答案脑图绑定书写；评论控制卡片文字/图片/合并评论，包括折叠评论。评论中的笔迹需两项同时开启。过滤在内容读取阶段完成，关闭时不读取对应手写资源或暂存评论资产；PDF、Markdown、快速预览同源。摘录底图保留，已烧录在图片像素中的笔迹无法单独剥离。
- `recordIds` 未提供才允许全量；数组含空时是严格白名单，并按请求顺序去重。不可用或读取失败的题卡跳过并返回 `missing`。
- `include.answer=false` 跳过答案匹配及 HTML 生成；导出读取不生成逐卡预览运行脚本，PDF 只装一次手写绘制器。
- PDF（b57 起）逐题冻结为外置 unit 脚本，主 HTML 只含轻量清单，正文不全量累计。图片原始 data URI 和手写档案逐卡写入 UTF-8 `.js` 资源，片段只携带图片标记，渲染器按需加载对应脚本，同媒体 ID/手写 hash 复用。原生复制脚本到本次渲染页目录，由脚本回填图片 src；不再把二进制转 JS 字符串后写图片，也不使用跨目录 file:// 图片。PDF 任务资源复制后即删除源暂存目录，成功、失败及取消统一清理渲染目录；手写资源在当前片段绘制前回填。Markdown 保留最近五批。
- 完整预览已删除。`previewLimit` 只支持 1–3，未提供也最多三题；响应包含 `count/previewCount/truncated/missing`，全部题目使用正式导出。
- 每页题数为 auto/1/2/3；答案位置为逐题/文末。固定题数按题组换页、保留书写空间，溢出时沿段落行/不可拆元素边界续页；不再依赖长节点裁切。题目与答案的独立手写画布统一按比例限制显示尺寸；底图叠加笔迹维持底图坐标。完整历史与概要分别组装；来源路径始终根到父级，不包含题目标题。
- `mistakeExportPreparationStatus` 返回 prepared/total；原生准备任务读取该进度。取消在逐题及批次让路点检查。
- Markdown 来源不含内部卡片/脑图 ID。系统保存接口无完成回执，打开面板不等于用户已保存。

## 验证边界
自动化与浏览器检查覆盖选题顺序、去重、异常跳过、公式、布局、预览入口及分段画布；原生文件资源脚本加载、内存峰值和普通 UIWebView 触摸必须另做 MN4 真机验收。

答案筛选沿用共享查找入口的直接父级名称硬匹配，适用于正式 PDF/Markdown 和快速预览；被排除的候选不会进入答案渲染及资产暂存。没有同父级候选时显示未匹配到答案，不自动携带其他章节的同名卡。


## b57 分页引擎

准备上下文互斥并独立持有取消标志；读取失败的题卡可计入 missing，文件写入、公式转换、取消等错误必须终止任务，不得当作缺失题目跳过。选项和题目顺序在准备入口复制，正文逐题落盘，不重新匹配已准备的答案。

`pdfSourceDirectory` 属于本次任务，`pdfAssets` 同时列出 unit/image/drawing 脚本；外置 unit 内容不嵌入主文档。先用有界分页器计算页数，再用同一分页器重建并逐页输出；内存中保留当前题及其未消费续页，不保留整套题目 DOM。截图所属 iframe document 只含当前页，画布在 finally 中清零。固定图像倍率在两轮分页前锁定。

公式通过 MathML 中的 TeX annotation 转为 KaTeX HTML，使用本地字体和 CSS；没有 TeX annotation 的 MathML 明确报错，不静默漏画。预览与正式导出使用同一分页链路，预览仍限前三题。

当前以整题为读取和暂存单位，单题极大正文可能影响峰值。JPEG 写入器最终组装的 PDF 与原生 NSData 内存用量仍随输出大小增长。
