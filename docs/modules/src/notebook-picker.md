# 学习集与答案脑图选择器

## 职责

`chooseNotebook` 在当前学习窗口中打开独立的紧凑 WebView 选择窗，返回所选原始项目；学习集选择和答案脑图选择共用此入口。保留 0.08 秒延迟，避免在导航回调中直接呈现。

## 窗口与交互

- 选择框和 WebView 只占紧凑内容尺寸，宽度最多 480，高度按项目数收缩、最多 560；窄窗口预留边距。父级透明触控层覆盖当前原生窗口，但不绘制白底或暗化遮罩。
- 选择器挂在学习视图所属的原生窗口，与插件页面同层，并显式置于子视图前端；不只依赖绘制 `zPosition`。打开期间框外点击由透明触控层接收，不传给底下插件页面，不关闭选择器，避免页面抢走触控。
- 原生 WebView 与其滚动层均显式透明；网页仅在圆角选择框内使用柔化背景，列表项不另铺纯白底，支持系统明暗配色。
- 名称完整转义并允许换行；搜索只过滤显示，不改变原始项目索引。长列表在选择框内部滚动，标题、取消和搜索保持可见。
- 取消按钮、生命周期关闭和被新选择窗替换都返回未选择，并移除完整透明触控层，恢复底下页面操作；旧窗口回调不能修改或关闭当前选择。框外点击不取消，取消使用明确按钮。

## 验证边界

原生 mock 测试覆盖返回值、取消、过期回调、窗口尺寸、两层透明设置，以及与插件窗口同层的命中顺序、框外点击隔离和关闭后触控恢复。浏览器夹具用于核对生成 HTML 的搜索和渲染，不等同于 MarginNote 真机透明合成、触摸或窗口旋转验收。
