# window-controls.ts — 原生窗口工具控件

## 职责

- 统一读取、规范化插件窗口关闭按钮的左右位置。
- 一次计算关闭、定位、刷新、候选答案和标题拖拽区的原生坐标。
- 统一创建答案窗口的关闭 `✕`、定位 `↗`、刷新 `↻` 字符按钮，各控件使用相同槽位尺寸。字符由 iOS 系统字体渲染，不依赖图片资源或 MarginNote 未暴露的 SF Symbols API。

## 边界

- 只提供布局和按钮工厂，不负责显示、隐藏、复位或刷新窗口内容。
- 设置切换的通知链由 `WebPanelController → plugin → answer-card-view` 负责。

## 验收

答案窗口与插件页面使用同一位置设置；切换设置时已存在答案窗口立即重排，关闭状态保持关闭。
