# answer-card-view.ts — 答题卡原生视图
## 职责
答题卡浮层原生容器：手势拖拽/缩放（单注册）、关闭/定位/刷新工具、缩放边界，以及仅在窗口显示期间运行的最前层校正。

复习评分控件使用透明 WebView 绘制胶囊底色、圆点和等级文字，与关闭胶囊使用相同高度、圆角与底色透明度；原生按钮承接点击并同步实际命中宽度。点击三圆点展开整组横向等级按钮，选择任一等级立即提交；外部点击监听不取消原有点击，关闭窗口时移除。绘制视口在状态切换时不变，整枚胶囊的弹性宽度过渡由 `answer-review-controls.ts` 实现；CSS 动效遵循减少动态效果。

评分层在重排及显示期间的置顶校正中清理自身、滚动层和内部子视图背景，防止宿主在加载后恢复白底；不清除答案正文背景。胶囊固定在关闭胶囊另一侧上角，36pt 高，两侧边距及顶部均为 6pt；折叠宽 64pt，展开宽 132pt，窄窗口依剩余空间收紧，保持第一行，不下移正文。视窗图标由透明原生 UIView 形状绘制，不嵌入独立 WebView。

评分绘制页通过 `native-control-surface.ts` 管理：答案窗口挂载后才加载，加载完成后应用最新状态。重新显示时确认绘制函数与根节点仍存在，缺失或加载失败时恢复一次；关闭时使旧回调失效。等级胶囊仍只对当前复习题显示，不能给其他题目的答案评分。

beta.68：这里的拖拽/缩放指窗口几何；窗口内卡片内容的手势由renderCardHtml嵌入的src/card-preview.ts统一管理，与Web CardPreview一致，不能另外绑定内容缩放。

## 验收
双指缩放不与面板冲突；关闭/定位/刷新按钮触达达标；窗口按钮方向变更只重排现有窗口，不创建、不显示、不复位；关闭窗口会停止置顶定时器。
