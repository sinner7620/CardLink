# main.jsx — 面板应用（主页与全部功能页）

beta.68：题目/答案iframe已统一到CardPreview，内容控制器在src/card-preview.ts。main不再持有三套预览缩放代码；详情胶囊跨标题与标签两行居中，标签限制在左列。长列表虚拟化尚未实施。

## 职责
面板单页应用：App 壳（topBar/导航/页签状态）与五个功能页组件（错题本/总览/待复习/设置/导出）、错题详情侧栏、任务式导出状态机、连通测试、Markdown 预览渲染。
## 页面
- 错题本（默认页）：列表/筛选/详情侧栏/批量操作
- 总览：统计卡/来源分布/三档占比/最近添加
- 待复习：到期队列/复测评价/完整原题懒加载（A+B）
- 设置：答案匹配/错题管理/调试功能/联通测试
- 导出：范围与筛选/包含内容/页面密度/答案位置/文件/预览导出（批次 A-D 重做后形态）
## 边界
- App 级错误以顶栏下方的可关闭浮层展示，不占用内容布局空间；长错误文字在浮层内滚动，顶栏不覆盖提示。
- 组件经 docs/modules/web/main 导出名供渲染冒烟测试
- pdfTask 状态机与原生任务表通过 pdfTaskStatus/pdfTaskCancel 轮询命令交互
- React 独占面板 DOM；复习摘要、响应式布局和选择图标均在组件/CSS 内实现，不允许引入 DOM 注入补丁层
## 验收
九组件 renderToString 冒烟通过；切页/筛选/导出交互见 pages/export.md 验收。

导出页六个单选控件使用 ExportSelect 网页菜单，支持点击/触摸外部关闭、Escape 和方向键，避免依赖普通 UIWebView 的原生 select 弹层；学习集筛选继续使用网页多选。底栏只提供最多三题的快速预览；完整预览入口和全量请求逻辑已删除，全部题目使用导出文件。任务 preparing 状态也可轮询、恢复和取消，generated 的文案仅报告已生成并打开保存面板。


## 错题本列表工具条

工具条沿用现有悬浮胶囊，按多选、搜索、筛选、排序排列；不单独显示总题数；启用筛选后，只在筛选图标角标显示结果数量。筛选使用待复习页的 `ReviewQueueFilters`（等级多选、学习集/脑图来源树及重置），排序菜单通过 `ReviewSortOptions` 共用五种排序，并调用 `sortReviewRecords`，默认剩余天数由少到多。筛选、排序图标共用 `Icon` 的 filter/sort；原有向下展开的分类、等级、日期筛选行移除。弹层挂到 body，避免被列表滚动容器裁剪，支持外部点击、Escape 和列表滚动关闭，弹层自身可独立滚动。搜索和批量全选针对筛选、排序后的可见列表，筛选来源仍由完整记录生成。

## OCR 数据库（v2.4.7-b28）

设置 → 错题管理挂载 `OCRDatabase.jsx`。工作台打开、恢复、刷新或开始内容查询时核对错题题干，列表与数据库页共享 SQLite FTS 候选查询。授权图片识别和手动队列共享截图组件，点击结果后经原有错题记录 ID 定位原卡。完整行为见 [错题 OCR 数据库](../../design/ocr-mistake-library.md)。
