# main.jsx — 面板应用（主页与全部功能页）

beta.68：题目/答案iframe已统一到CardPreview，内容控制器在src/card-preview.ts。main不再持有三套预览缩放代码；详情胶囊跨标题与标签两行居中，标签限制在左列。长列表虚拟化尚未实施。

## 职责
面板单页应用：App 壳（topBar/导航/页签状态）与五个功能页组件（错题本/总览/待复习/设置/导出）、错题详情侧栏、任务式导出状态机、连通测试、Markdown 预览渲染。
## 页面
- 错题本（默认页）：列表/筛选/详情侧栏/批量操作
- 总览：统计卡/来源分布/三档占比/最近添加
- 待复习：到期队列/复测评价/完整原题懒加载（A+B）
- 设置：答案匹配/错题管理/调试功能/联通测试
- 导出：范围与筛选/包含内容/页面密度/答案位置/文件/预览导出（批次 A-D 重做后形态）
## 边界
- App 级错误以顶栏下方的可关闭浮层展示，不占用内容布局空间；长错误文字在浮层内滚动，顶栏不覆盖提示。
- 组件经 docs/modules/web/main 导出名供渲染冒烟测试
- pdfTask 状态机与原生任务表通过 pdfTaskStatus/pdfTaskCancel 轮询命令交互
- React 独占面板 DOM；复习摘要、响应式布局和选择图标均在组件/CSS 内实现，不允许引入 DOM 注入补丁层
## 验收
九组件 renderToString 冒烟通过；切页/筛选/导出交互见 pages/export.md 验收。
