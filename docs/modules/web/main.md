# main.jsx — 面板应用（主页与全部功能页）

beta.68：题目/答案iframe已统一到CardPreview，内容控制器在src/card-preview.ts。main不再持有三套预览缩放代码；详情胶囊跨标题与标签两行居中，标签限制在左列。长列表虚拟化尚未实施。

## 职责
面板单页应用：App 壳（topBar/导航/页签状态）与五个功能页组件（错题本/总览/待复习/设置/导出）、错题详情侧栏、任务式导出状态机、连通测试、Markdown 预览渲染。
## 页面
- 错题本（默认页）：列表/筛选/详情侧栏/批量操作
- 总览：统计卡/来源分布/三档占比/最近添加
- 待复习：到期队列/复测评价/完整原题懒加载（A+B）
- 设置：答案匹配/错题管理/调试功能/联通测试
- 导出：范围与筛选/包含内容/页面密度/答案位置/文件/预览导出（批次 A-D 重做后形态）
## 边界
- App 级错误以顶栏下方的可关闭浮层展示，不占用内容布局空间；长错误文字在浮层内滚动，顶栏不覆盖提示。
- 组件经 docs/modules/web/main 导出名供渲染冒烟测试
- pdfTask 状态机与原生任务表通过 pdfTaskStatus/pdfTaskCancel 轮询命令交互
- React 独占面板 DOM；复习摘要、响应式布局和选择图标均在组件/CSS 内实现，不允许引入 DOM 注入补丁层
## 验收
九组件 renderToString 冒烟通过；切页/筛选/导出交互见 pages/export.md 验收。

导出页六个单选控件使用 ExportSelect 网页菜单，支持点击/触摸外部关闭、Escape 和方向键，避免依赖普通 UIWebView 的原生 select 弹层；学习集筛选继续使用网页多选。底栏只提供最多三题的快速预览；完整预览入口和全量请求逻辑已删除，全部题目使用导出文件。任务 preparing 状态也可轮询、恢复和取消，generated 的文案仅报告已生成并打开保存面板。


## 错题本列表工具条

工具条沿用现有悬浮胶囊，按多选、搜索、筛选、排序排列；不单独显示总题数；启用筛选后，只在筛选图标角标显示结果数量。筛选使用待复习页的 `ReviewQueueFilters`（等级多选、学习集/脑图来源树及重置），排序菜单通过 `ReviewSortOptions` 共用五种排序，并调用 `sortReviewRecords`，默认剩余天数由少到多。筛选、排序图标共用 `Icon` 的 filter/sort；原有向下展开的分类、等级、日期筛选行移除。弹层挂到 body，避免被列表滚动容器裁剪，支持外部点击、Escape 和列表滚动关闭，弹层自身可独立滚动。搜索和批量全选针对筛选、排序后的可见列表，筛选来源仍由完整记录生成。

## 错题原题引用拖放

- 网页发出长按请求，原生窗口手势与请求配对后负责悬浮卡片、目标高亮和松手放置。传统面板按发起请求的 WebView 换算触点，场景面板使用原生命中的 WebView。
- 传统面板收到原生 `unavailable` 时，松手位置在面板外才走既有网页拖出回退。场景面板使用原生放置结果。
- 落点同时命中多级父子卡片时，逐级排除完整包围命中后代卡片的上级卡片。上级卡片自身的独占区域仍可链接。剩余的多个候选通过 UIKit 命中视图及其父视图定位最上层卡片，拖动高亮和松手写入共用此规则。
- 原生命中视图缺少笔记身份时，插件使用转换到画布后的四条边匹配候选，唯一匹配才允许链接。身份与边界均无法区分时维持歧义提示。调试模式在此类松手事件记录 `target.ambiguous`，含命中视图类名、边界和节点几何。
- 放置成功后，原题和落点卡分别保存指向对方的原生链接。重拖可补齐历史单向链接，已有的方向保持原样。两侧都回读成功时才显示双向链接成功。
- `nativeGesture.accepted` 和 `nativeGesture.rejected` 记录触点来源、可计算的时间差与坐标差和匹配结果。传统面板在 `boot.appRendered` 记录根元素顶部及网页视口偏移。
- 错题详情的 `mistakeDetail` 原题响应可带 `linkedQuestions`。标签栏在加号右侧以中性浅灰显示链接题名，和普通标签共用字级、圆角和间距。原有标签保持完整，链接题名按空间截断，整栏保持单行。
- **Do** 用链接打开已收录的错题，用加号按钮打开标签编辑器。**Don't** 用静态标签触发跳转，或给未收入错题本的题名提供无效链接。
- 打开链接时，错题列表会展开并滚动到选中的目标行。目标被搜索或筛选排除时，列表临时显示该题，保留原搜索和筛选条件。

## OCR 数据库（v2.4.7-b28）

设置 → 错题管理挂载 `OCRDatabase.jsx`。工作台打开、恢复、刷新或开始内容查询时核对错题题干，列表与数据库页共享 SQLite FTS 候选查询。授权图片识别和手动队列共享截图组件，点击结果后经原有错题记录 ID 定位原卡。完整行为见 [错题 OCR 数据库](../../design/ocr-mistake-library.md)。

## Harness AI 界面

- **AI 分析**使用 assistant-ui 的 Thread、ThreadList、Markdown Text 和 Sources。等待和工具活动使用官方 Typing Indicator、Run Activity、Tool Timeline、Tool Call 和 Tool Error。ExternalStoreRuntime 接入实际运行阶段，展开运行详情可查看审核和结构化工具结果。卡片与统计来源只打开已核验的本地证据。审核档位、上下文与费用详情从输入区打开，完整会话导出位于会话菜单。
- **AI 数据报告、证据与诊断**由官方 DataTable 和 shadcn/ui 组件组装，错题原题预览复用 CardLink 的 CardPreview。
- **模型与密钥设置**使用官方 Settings Panel。保存连接、获取目录、手动测试和保存并启用各有入口。助手、审核各自授权，审核可跟随助手或选用独立连接。官方 Model Selector 在设置中展示模型目录，也可在会话输入区切换当前助手绑定。
- **分支与公开交互**使用官方 Message Branches、Edit Message、Conversation Search、Question Flow 和 Agent Plan。分支和待答选项由 Harness SQLite 持久化。聊天可展开本地来源、只读可视化、复习队列、题图和按需匹配答案。
- 页面仍通过 H1 白名单命令与原生侧通信。场景模式未启用时显示启用指引。安全与统计口径见 [H1 §12–13](../../design/cardlink-harness-h1.md#12-安全密钥与隐私规范)。
