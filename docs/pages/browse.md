# 功能页：错题本

## 入口

`main.jsx` 的 `MistakeBrowser` 与 `MistakeDetail`。

详情预览的悬浮工具条「手写」按钮直接请求该错题原题的整卡书写批注窗口，不展示额外 CardLink 作答界面。继续未完成作答纸或新建由宿主决定。确认保存后刷新当前题目详情。宿主版本及启用要求见[整卡手写作答](handwrite.md)。

## 结构

列表滚动区域从窗口顶部开始，内容可以从半透明导航栏背后滚过。初始顶部留白由列表内搜索栏的上边距提供，搜索栏粘附位置为导航栏下8px；工作区不再整体预留顶栏高度。详情单独保留顶部内边距，始终显示与自动隐藏列表均适用。

个性设置可启用“自动隐藏”：列表、搜索和筛选工具条从左侧拉出时，详情的左边缘跟随列表右边缘移动，实际宽度随之横向调整，始终填满右侧剩余区域；列表收起后详情重新占满工作区。列表宽度最多 310px，且不超过工作区的 46%。已有可用详情时点击详情区域或按 Esc 收起；拖动或点击列表右边缘入口可展开，也可向左拖回。两区域共用列表露出宽度，同帧更新列表位置和详情宽度；松手使用同一缓动落位，中途反向拖动从当前可见位置继续。纵向滚动保留，系统减少动态效果时取消落位动画。隐藏不卸载列表，保留筛选、选择和滚动状态；“始终显示”维持原布局。

列表与详情直接铺在同一白色底层，以一条竖线分隔，不再用页面底色、外边距或卡片外框区分。列表自身贯通上下并负责滚动；搜索、多选、数量和折叠筛选组成滚动区外的毛玻璃悬浮条，筛选展开后进入第二行，批量操作进入其后续行。分类与日期弹层由工具条持有，不受列表滚动裁剪，也不会落到详情层后方。

## 功能

搜索、分类级联、等级、日期与收藏筛选；批量改级、导出和取消；详情题目/答案预览、等级、自定义标签和定位。详情操作条的定位按钮按当前预览切换目标：题目页定位原题，答案页在 MarginNote 浮窗中定位当前选中的答案候选；切换候选后定位目标同步改变，没有答案时给出提示。列表工具条内部以图标和文字为主，取消重复的小卡片底色，仅搜索框保留自身边框。详情操作条采用可透出正文的半透明毛玻璃，在空间足够时显示文字，并按删除→定位→答案→题目的顺序逐级收起文字。

## 边界

- 题目与答案共用 `CardPreview`：经典面板使用 HTML 与 `mountCardPreview`；场景面板使用宿主 `/notes/{id}/render` 长图和同一缩放手势。长图不执行 HTML 内部评论折叠、双击绑定手写等交互，读取失败显示重试，见[手写与场景预览](handwrite.md)。
- 列表只传输工作台记录。打开或刷新详情先读取原题（`mistakeDetail` 的 `content: "question"`），同步原卡标题与标签，但跳过答案匹配、答案 HTML 生成和传输。点击答案才发送 `content: "answers"`，不重复生成原题；当前详情内切换题目/答案复用已读答案，刷新详情或保存批注后失效。读取失败显示重试。快速切题丢弃旧请求结果，避免串题。
- 大列表项使用渲染隔离与屏外跳过，项目属性未变化时不重复渲染；搜索使用延迟查询，避免输入和窗口缩放阻塞主线程。

## 验收

筛选与列表实时一致；批量操作后队列实时更新；外层无卡片框和异色边沟；筛选弹层不被详情遮挡；窄宽度下悬浮条不越界，等级/剩余天数纵向拼接且对齐。

## 子卡答案与自动隐藏列表（2026-09-27）

原题预览在当前绑定采用子卡答案（包括混合模式）、题目颜色符合配置时，省略题目的直接子卡片内容。混合模式另有绑定答案脑图时同样隐藏，避免把已经识别为答案的内容放进原题。纯答案脑图模式或题目颜色不符合配置时保留子卡内容。该规则同样用于待复习原题与共用的原题内容出口，不修改源卡片。

自动隐藏列表不再用透明遮罩阻挡详情。点击详情控件可同时执行操作和收起列表，点击预览 iframe 内容也能收起列表。展开后的列表可横向拖回；普通点击保留原控件目标，超过横向拖动阈值才接管指针。详情悬浮工具栏不再对位置坐标追加动画，以免与详情宽度动画叠加产生过度位移。

## 列表交互与刷新（2026-10-08）

点击失效错题读取详情失败后，保留错误提示并在后台同步列表。后台刷新收齐分页后一次性更新，期间保留完整列表和当前滚动位置；分页失败保留原列表。首次加载与显式刷新仍逐页显示，显式刷新完成后恢复外层侧栏的滚动位置。

自动隐藏模式下，仅在已有可用题目详情时点击详情区域才自动收起列表。空详情、顶栏点击、拖动窗口、刷新和切换顶栏页签不会触发收起。仍可用小竖条主动收放或拖动；竖条位于列表右边缘并随列表移动，展开宽度最多 310px、且不超过工作区的 46%。标签按剩余空间显示，不再固定限制为 76px。

顶栏窗口操作分为关闭、重置窗口、刷新错题列表三键。重置窗口（窗口图标）只恢复位置与大小；刷新只回读现有错题原卡的标题、标签、来源及可用状态，不扫描新错题、不回写原卡。原卡缺失时保留历史并灰显「原卡片不可用」；原卡恢复后刷新可恢复可用状态。原卡移除托管错题标签则沿用标签即身份规则，归档历史后移出列表。普通页面加载仍使用持久化快照；外部编辑后可显式刷新整份列表，不必逐题打开。

批量标记按实际答案来源过滤：纯子卡片模式按已绑定题目颜色与直接父子关系排除答案，不再用同脑图的全量答案索引排除题目。独立答案脑图的过滤继续保留。没有配置题目颜色时不猜测子卡答案身份。
## 答案索引处理

错题详情切换到答案、待复习打开答案时，索引缺失会弹出处理选项，并显示当前绑定答案脑图及上次刷新时间。取消后保留原题；可通过「处理答案索引」或再次打开复习答案重试。索引缺失结果不作为成功详情缓存。
