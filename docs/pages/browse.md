# 功能页：错题本

## 入口

`main.jsx` 的 `MistakeBrowser` 与 `MistakeDetail`。

## 结构

列表与详情直接铺在同一白色底层，以一条竖线分隔，不再用页面底色、外边距或卡片外框区分。列表自身贯通上下并负责滚动；搜索、多选、数量和折叠筛选组成滚动区外的毛玻璃悬浮条，筛选展开后进入第二行，批量操作进入其后续行。分类与日期弹层由工具条持有，不受列表滚动裁剪，也不会落到详情层后方。

## 功能

搜索、分类级联、等级、日期与收藏筛选；批量改级、导出和取消；详情题目/答案预览、等级、自定义标签和定位原题。列表工具条内部以图标和文字为主，取消重复的小卡片底色，仅搜索框保留自身边框。详情操作条采用可透出正文的半透明毛玻璃，在空间足够时显示文字，并按删除→定位→答案→题目的顺序逐级收起文字。

## 边界

- 题目与答案预览共用 `CardPreview` 和 `mountCardPreview` 手势内核。
- 列表只传输工作台记录；题目和答案 HTML 在打开详情时生成。
- 大列表项使用渲染隔离与屏外跳过，项目属性未变化时不重复渲染；搜索使用延迟查询，避免输入和窗口缩放阻塞主线程。

## 验收

筛选与列表实时一致；批量操作后队列实时更新；外层无卡片框和异色边沟；筛选弹层不被详情遮挡；窄宽度下悬浮条不越界，等级/剩余天数纵向拼接且对齐。
