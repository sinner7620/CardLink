# 功能页：错题本

## 入口

`main.jsx` 的 `MistakeBrowser` 与 `MistakeDetail`。

## 结构

个性设置可启用“自动隐藏”：列表、搜索和筛选工具条从左侧拉出时，详情的左边缘跟随列表右边缘移动，实际宽度随之横向调整，始终填满右侧剩余区域；列表收起后详情重新占满工作区。列表宽度最多 340px，且不超过工作区一半。点击列表外部或按 Esc 收起；从左缘拖动或点击入口可展开，也可向左拖回。两区域共用列表露出宽度，同帧更新列表位置和详情宽度；松手使用同一缓动落位，中途反向拖动从当前可见位置继续。纵向滚动保留，系统减少动态效果时取消落位动画。隐藏不卸载列表，保留筛选、选择和滚动状态；“始终显示”维持原布局。

列表与详情直接铺在同一白色底层，以一条竖线分隔，不再用页面底色、外边距或卡片外框区分。列表自身贯通上下并负责滚动；搜索、多选、数量和折叠筛选组成滚动区外的毛玻璃悬浮条，筛选展开后进入第二行，批量操作进入其后续行。分类与日期弹层由工具条持有，不受列表滚动裁剪，也不会落到详情层后方。

## 功能

搜索、分类级联、等级、日期与收藏筛选；批量改级、导出和取消；详情题目/答案预览、等级、自定义标签和定位。详情操作条的定位按钮按当前预览切换目标：题目页定位原题，答案页在 MarginNote 浮窗中定位当前选中的答案候选；切换候选后定位目标同步改变，没有答案时给出提示。列表工具条内部以图标和文字为主，取消重复的小卡片底色，仅搜索框保留自身边框。详情操作条采用可透出正文的半透明毛玻璃，在空间足够时显示文字，并按删除→定位→答案→题目的顺序逐级收起文字。

## 边界

- 题目与答案预览共用 `CardPreview` 和 `mountCardPreview` 手势内核。
- 列表只传输工作台记录；题目和答案 HTML 在打开详情时生成。
- 大列表项使用渲染隔离与屏外跳过，项目属性未变化时不重复渲染；搜索使用延迟查询，避免输入和窗口缩放阻塞主线程。

## 验收

筛选与列表实时一致；批量操作后队列实时更新；外层无卡片框和异色边沟；筛选弹层不被详情遮挡；窄宽度下悬浮条不越界，等级/剩余天数纵向拼接且对齐。

## 子卡答案与自动隐藏列表（2026-09-27）

原题预览在当前绑定采用子卡答案（包括混合模式）、题目颜色符合配置、且没有另外绑定答案脑图时，省略题目的子卡片内容；另有绑定答案脑图时保留原题子卡片。该规则同样用于待复习原题与共用的原题内容出口，不修改源卡片。

自动隐藏列表不再用透明遮罩阻挡详情。点击详情控件可同时执行操作和收起列表，点击预览 iframe 内容也能收起列表。展开后的列表可横向拖回；普通点击保留原控件目标，超过横向拖动阈值才接管指针。详情悬浮工具栏不再对位置坐标追加动画，以免与详情宽度动画叠加产生过度位移。
