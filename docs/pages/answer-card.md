# 功能页：答题卡（浮层）
## 入口
工具栏「查找答案」→ showAnswerCard（answer-card-view + card-html）。

答案索引尚未建立或读取异常时，弹出「答案索引需要处理」，显示当前原题脑图绑定的答案脑图名称和上次刷新时间（无有效记录显示「暂无刷新记录」）。用户可选择「刷新索引」、原生「取消」或「换绑」。刷新仅重建所示目标的索引，成功后重试原题读取；换绑进入原题的答案来源选择流程，取消不修改索引或绑定。等待期间切换学习集时不在新学习集自动查找原题。

默认窗口最大 560×620，在正常平板视区内从顶部至少 104 点以下布局，避让软件工具条；手动拖动和缩放保留，复位时使用新的默认位置。
## 功能
答案 HTML 渲染（含手写 canvas）、拖拽/缩放（与面板锚定策略一致）、关闭/定位/刷新按钮。定位按钮调用 MarginNote 原生浮窗聚焦当前答案卡片；窗口显示期间以固定高层级和定时前置校正保持在最前方，关闭后停止校正。

答案卡片的脑图绑定手写初始隐藏，在窗口内双击或双轻点切换显示；拖动与缩放不会误触切换。
## 答案窗口控件

自 2.4.5-b46 起移除实验性液态玻璃运行时与附带源码，恢复普通控件材质。答案正文不再被采集为玻璃纹理，窗口不再注入玻璃画布或轮询其状态。

## 验收
图片+手写/纯手写/纯文本三形态正确；缩放边界无跳变；后打开卡片编辑器时答案窗口重新置顶，关闭后不再参与层级校正。

复习模式下，顶部中央三圆点胶囊可展开为「不会／不熟／掌握」。选择后为当前队列题目保存复测结果，成功后自动进入下一题；失败保留当前题。

等级胶囊与关闭胶囊使用相同的 36pt 高度、18pt 圆角和底色不透明度 0.96；折叠为 64pt 宽，常规展开宽度 132pt，窄窗口按剩余空间收紧。透明 WebView 的绘制视口在展开／收起时保持固定，胶囊背景及内容通过 CSS 弹性宽度过渡，不缩放形状；减少动态效果时取消过渡。关闭胶囊在左上时等级胶囊固定右上，反之固定左上，两侧均距边 6pt，始终保留在第一行。候选答案按钮参与避让，不下移正文。复原按钮以透明原生形状绘制与插件窗口一致的视窗图标，避免独立 WebView 内容层出现白底；仍执行恢复窗口位置／大小并重新载入当前答案。
