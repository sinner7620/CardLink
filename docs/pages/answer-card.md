# 功能页：答题卡（浮层）
## 入口
工具栏「查找答案」→ showAnswerCard（answer-card-view + card-html）。
## 功能
答案 HTML 渲染（含手写 canvas）、拖拽/缩放（与面板锚定策略一致）、关闭/定位/刷新按钮。定位按钮调用 MarginNote 原生浮窗聚焦当前答案卡片；窗口显示期间以固定高层级和定时前置校正保持在最前方，关闭后停止校正。

答案卡片的脑图绑定手写初始隐藏，在窗口内双击或双轻点切换显示；拖动与缩放不会误触切换。
## 验收
图片+手写/纯手写/纯文本三形态正确；缩放边界无跳变；后打开卡片编辑器时答案窗口重新置顶，关闭后不再参与层级校正。
