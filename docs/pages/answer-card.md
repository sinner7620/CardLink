# 功能页：答题卡（浮层）
## 入口
工具栏「查找答案」→ showAnswerCard（answer-card-view + card-html）。

答案索引尚未建立或读取异常时，弹出「答案索引需要处理」，显示当前原题脑图绑定的答案脑图名称和上次刷新时间（无有效记录显示「暂无刷新记录」）。用户可选择「刷新索引」、原生「取消」或「换绑」。刷新仅重建所示目标的索引，成功后重试原题读取；换绑进入原题的答案来源选择流程，取消不修改索引或绑定。等待期间切换学习集时不在新学习集自动查找原题。

默认窗口最大 560×620，在正常平板视区内从顶部至少 104 点以下布局，避让软件工具条；手动拖动和缩放保留，复位时使用新的默认位置。
## 功能
答案 HTML 渲染（含手写 canvas）、拖拽/缩放（与面板锚定策略一致）、关闭/定位/刷新按钮。定位按钮调用 MarginNote 原生浮窗聚焦当前答案卡片；窗口显示期间以固定高层级和定时前置校正保持在最前方，关闭后停止校正。

窗口顶部可拖动。批注工具条只占用其外框范围，展开、收起或切换颜色面板时，顶部可拖动区域随工具条宽度调整。

答案卡片的脑图绑定手写初始隐藏，可用正文里的「显示脑图手写」按钮展开。

答案预览手写批注默认关闭，可在「设置 → 个性设置 → 操作与窗口 → 答案预览手写批注」开启，每次开启均需确认。关闭后保留已保存的批注，重新开启即可查看或编辑。

普通评论显示为「评论 1」「评论 2」等可展开条目，子卡和链接卡内的评论也在各自内容中显示。首次预览时沿用宿主提供的折叠状态，手动展开或收起后记住预览选择。主答案卡的 CardLink 批注图片在底部的「答案批注」中查看。

阅读状态支持系统滚动和双指捏合缩放。展开右上角工具条即可批注，页面回到原始比例。工具条与窗口关闭按钮同高，最左侧是撤销、重做，随后是钢笔、荧光笔和橡皮擦。撤销、重做和收起按钮的点击区域占满工具条高度。再次点击选中的笔可调笔宽，笔宽下方是预设颜色和自定义颜色。再次点击选中的橡皮擦可调大小和局部、整笔擦除方式。工具参数跨题保留。Apple Pencil 或鼠标用于书写，单指滑动带惯性，双指捏合时答案正文和笔迹一起缩放，工具条保持原大小。

涂抹擦除默认开启。用钢笔在已有笔迹上快速来回涂抹，可擦除命中的整笔，支持横向、纵向和斜向涂抹，也可撤销。已保存的开关选择继续生效。

新绘制的荧光笔使用 Drawesome 的平头笔形与正片叠底混色，保留已有的颜色和笔宽设置。旧荧光笔迹沿用其原有外观。Apple Pencil 悬停在答题纸上会显示当前工具的预览点。宿主提供悬停距离时，笔尖越接近屏幕，预览点越接近实际笔宽；只有悬停位置时，预览点保持固定大小。

笔迹有变化时，收起工具条会先保存可编辑草稿，再合成批注图片。本机保存成功后回到正文。在已有图片与草稿一致的情况下，原样进入再收起会复用图片。最新图片在预览底部默认折叠，展开时读取。同一答案卡从不同原题打开时共用草稿，重新展开工具条可继续编辑。当前暂停自动写入原卡评论，草稿和预览图均保存在本机。草稿或图片保存失败时留在批注模式，可以重试。旧版草稿打开时按原坐标格式读取，b31 的本机笔迹按宽度换算，文字重排时可能错位。b30 WebView 笔迹仍留在原存储位置。

新笔迹随落笔所在的图片、公式或正文块移动和缩放。段落换行时，笔迹跟随段落的位置与大小。旧草稿中没有内容锚点的笔迹沿用原卡片坐标，顶部布局变化可能使它与正文的相对位置改变。

如果 Apple Pencil 偶尔整笔写不上，先在 iPad 的「设置 → Apple Pencil」关闭「随手写」，再回到答案窗口试写。此办法已在出现漏笔的设备上恢复书写。关闭后，系统手写转文字也会停用。 [Apple 随手写说明](https://support.apple.com/zh-hans/guide/ipad/ipad355ab2a7/ipados)

排查断触或缩放错位时，连点设置页版本号五次开启调试模式，再重新打开答案窗口。复现后结束批注，再到调试功能导出运行日志。日志的「答案书写」记录原生滚动、捏合及触摸交付设置的读回结果，以及 WebView 收到的触点生命周期、引擎提交与逐笔渲染分块数、涂抹擦除、页面几何和随内容重新定位的笔数。移动事件抽样记录，缺少落笔的接触移动单独记录。日志不包含笔迹坐标、草稿、答案正文或图片。
## 答案窗口控件

自 2.4.5-b46 起移除实验性液态玻璃运行时与附带源码，恢复普通控件材质。答案正文不再被采集为玻璃纹理，窗口不再注入玻璃画布或轮询其状态。

## 验收
图片+手写/纯手写/纯文本三形态正确；缩放边界无跳变；后打开卡片编辑器时答案窗口重新置顶，关闭后不再参与层级校正。

复习模式下，顶部中央三圆点胶囊可展开为「不会／不熟／掌握」。选择后为当前队列题目保存复测结果，成功后自动进入下一题；失败保留当前题。

等级胶囊与关闭胶囊使用相同的 36pt 高度、18pt 圆角和底色不透明度 0.96；折叠为 64pt 宽，常规展开宽度 132pt，窄窗口按剩余空间收紧。透明 WebView 的绘制视口在展开／收起时保持固定，胶囊背景及内容通过 CSS 弹性宽度过渡，不缩放形状；减少动态效果时取消过渡。关闭胶囊在左上时等级胶囊固定右上，反之固定左上，两侧均距边 6pt，始终保留在第一行。候选答案按钮参与避让，不下移正文。复原按钮以透明原生形状绘制与插件窗口一致的视窗图标，避免独立 WebView 内容层出现白底；仍执行恢复窗口位置／大小并重新载入当前答案。
