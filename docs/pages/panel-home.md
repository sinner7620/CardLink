# 功能页：面板壳与导航（主页）
## 入口
web/src/main.jsx `App` 组件；经典面板显隐由 WebPanelController/WebAddon 管理。软件达到 4.5.0 且当前场景允许时，SceneWorkbench 改用正式 AddonWebPanel 加载相同工作台，经 `/ui-state` 确认 `immersive === true` 后启用。低版本或不能确认场景时保留经典面板。通信与新接口条件见 [整卡手写作答](handwrite.md)。
## 结构
topBar（关闭/刷新 + 四页签导航）→ 页签内容 → 页脚状态。页签：错题本（默认主页）/总览/待复习/设置。错题本占满 topBar 下方的可用区域；其他页签自行持有页面留白。定位中的等待或失败通知固定叠加在 topBar 下方，不参与文档流，避免推动页面。
场景顶栏按用户指定改为顶部导航与窗口控制两组悬浮玻璃胶囊。去掉独立拖动提示横条及额外36px占位，正文保留40px导航高度，外围为8px半透明圆角内边框。导航高32px，宽度由各入口文字与数量决定，不再固定最高340px；选中背景按实际按钮位置和宽度测量，并在数量或布局变化时重测。宽窗口居中，窄窗口使用紧凑布局且保留数量，空间不足时导航可横向滚动，不压缩文字。窗口胶囊提供关闭/恢复大小/刷新；右下角黑色弧形条提供网页角部缩放触摸区域，可拖动缩放、点击打开尺寸面板，均不预留底部控件条，插件不施加最大宽度。自动隐藏列表通过按钮展开/收起，经典侧滑保留。新顶部按钮位于宿主拖动区域内，触摸可靠性仍需设备验证，宿主拖动未被禁用，角部缩放不能强行覆盖原生识别器；透明边框也不等同于系统级透景。详见 [整卡手写与场景面板](handwrite.md) 与 [WebGL玻璃方案评估](../design/liquid-glass-webgl-assessment.md)。

## 验收
切页响应即时；面板重开数据不闪烁；关闭面板图标高亮同步（beta.46）。


网页界面默认禁止文字选择与 iOS 长按菜单；文本输入框、textarea 和可编辑区域保留文字选择及编辑。题目/答案预览的独立 iframe 不加载该界面规则，正文仍可选择复制。

## 默认窗口预设

尺寸弹窗可选择内置或已保存的自定义预设作为默认值。预设2为720×520；未选择默认预设时使用该尺寸。顶部恢复大小、弹窗恢复默认和重新启动工作台统一读取默认预设，不再用上次临时调整的尺寸覆盖它。同一次使用中收起再展开仍恢复收起前的窗口大小。删除正在作为默认值的自定义预设后回退预设2。选择默认值不会立即改变当前窗口，可点击预设或恢复默认应用。
## 自建窗口透明度保护

经典工作台使用独立的 `panelSurface` 浮窗承载 WebView，与 UIViewController 的根视图分开，不在 viewDidLoad 中替换根视图。浮窗使用 `CardLinkWindowSurface`，通过 `src/window-opacity.ts` 拦截宿主 alpha 请求。答案、插件手写、历史作答与自建悬浮菜单复用该容器。子卡片答案遮挡层改为挂载到真实 `MindMapCanvas.layer` 的 backing CALayer，UIKit 载体不加入可见视图树，保留完全不透明的遮挡背景；菜单主动淡入淡出使用 `setWindowSurfaceOpacity`，内部按钮与其他背景材质保留原透明度。

透明度回调只在图层值变化时恢复，并移除 opacity 动画。经典窗口拖动和缩放共享识别器所有权，以起始几何计算位置，结束或关闭释放；跟手更新通过 `setWindowFrame` 关闭可用的 UIView 动画、清除位置和尺寸动画并恢复动画开关。答案窗口跟手更新也使用此接口。若原生子类创建失败，退回普通容器并记录控制台诊断，透明度保护不可用，但不得因此阻止打开做题菜单。

保护仅作用于 CardLink 创建的容器，不修改全局 UIView。AddonWebPanel 场景面板、宿主批注编辑器、MN Utils 悬浮球及祖先视图不属于本接口保护范围。不能把网页背景不透明等同于原生父视图不透明。
