# 功能页：面板壳与导航（主页）
## 入口
web/src/main.jsx `App` 组件；面板显隐由 WebPanelController/WebAddon 管理。
## 结构
topBar（关闭/刷新 + 四页签导航）→ 页签内容 → 页脚状态。页签：错题本（默认主页）/总览/待复习/设置。错题本占满 topBar 下方的可用区域；其他页签自行持有页面留白。定位中的等待或失败通知固定叠加在 topBar 下方，不参与文档流，避免推动页面。
## 数据
dashboard 先传 25 条首屏记录、绘制后续传；`loadSeqRef` 防旧请求覆盖新数据。首屏快照保存在 Web 本地缓存，冷启动和控制器恢复时先绘制缓存，再安静校验原生修订号。原生侧复用同一修订号的工作台聚合缓存，避免面板重显重复排序和统计。
## 验收
切页响应即时；面板重开数据不闪烁；关闭面板图标高亮同步（beta.46）。
