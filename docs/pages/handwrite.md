# 整卡手写作答

## 入口与行为

在错题本打开一道题的详情，点击预览工具条「手写」，或点击待复习队列中与定位、答案、历史同排的书写图标，直接打开该题原题的 MarginNote 原生书写批注窗口。详情即使当前显示答案，书写目标仍为这道错题的原题。队列书写不先加载完整详情。

确认原生批注编辑器打开后，工作台保留完整页面并调整为宽360、高600；不关闭、不切换mini小条，打开失败不改变尺寸。此临时尺寸不覆盖用户保存的窗口尺寸。公开场景接口提供size但未提供位置/停靠接口，左侧居中需要用户手动拖动，不能保证自动停靠。离开学习集或停用插件时仍正常清理。实际批注窗口与工作台的层级、触摸交互仍需设备确认。

不另设 CardLink 作答界面，不要求再次选卡或点击新建。先按原题 ID 读取批注版本，再调用 annotation-editor，传入 expectedRevision 和 confirm。按文档的普通批注模式不传 practice，不绑定学习集练习上下文；本次不指定历史 commentId。

## 版本、场景与面板

MarginNote 5 切换到场景模式后，CardLink 自动使用场景工作台。整卡手写需要当前场景模板允许 CardLink 加载。

宿主版本从 `Application.sharedInstance().appVersion` 读取，以 **5** 为主版本门限；`mn.version` 是 SDK 版本，不用于软件版本判断。低于门限或版本无法识别时使用经典面板，不创建场景面板、不请求新接口。

在 MarginNote 5，宿主当前学习控制器的 `immersiveMode` 决定面板类型。进入场景时由宿主允许创建的 `AddonWebPanel` 加载工作台，页面再确认场景通道就绪。当前模板未授权或面板加载失败时会提示原因。切回传统模式时使用经典面板，整卡手写不可用。

新面板按官方 `panel.loadPanel()`、`panel.showFloatingIn(studyController)` 显示，关闭调用 `hideFloating()`。不挂载不可见手写页、不调用未公开的原生批注入口。工作台界面复用，经典控制器继续承载原有业务与 PDF 服务。

场景清单入口为包根 `index.html`，显式引用 `/pkg/web-dist/` 资源。宿主页面地址为 `mnpanel://panel/index.html`，其 `/pkg/` 虚拟路径映射插件包根；该映射核对了参考刷题插件的 HTML 与真实包结构。不能将 URL 根直接当作包根。经典 WebView 保留 `web-dist/index.html` 及其相对资源路径。启动页显示当前阶段；版本、状态、确认请求各 5 秒超时，失败时关闭未完成启动的面板并提示原因。原生侧还有 20 秒启动计时，以应用渲染日志为完成确认，覆盖启动脚本本身未加载的情况；渲染成功或关闭面板会取消计时。

场景面板未成功启用时，手写入口保留不可用语义；点击只解释当前使用经典面板及启用条件，不发送定位或批注请求。忙碌中的按钮仍禁止重复点击。

页面通过 `mn.call` 请求原生业务；`onMessage` 同步返回接收确认，异步业务结果通过 `panel.post` / `mn:bridgeResponse` 返回。每次业务请求前重新检查场景状态；离开场景后停止请求并回退经典面板。重新显示和跨学习集恢复通过面板事件刷新原有数据。

场景顶栏按用户指定改为顶部两组悬浮胶囊：总览、错题本、待复习、设置共用导航胶囊，关闭、恢复大小、刷新共用窗口控制胶囊。移除独立 CardLink/横条及 body 顶部 36px 占位，外围增加8px半透明圆角玻璃风格内边框；导航在窗口中线居中，宽度最高340px，高32px，内容保留40px导航高度；窄于等于560px时隐藏导航数量徽标，保留入口名称。经典面板保持原布局。

右下角缩放手柄为黑色弧形拐角条，透明44×44px触摸区域覆盖网页边框右下角，不额外占一行；点击手柄打开尺寸弹窗，手柄仍支持拖动缩放和方向键微调。顶栏窗口图标恢复重置：场景面板直接恢复640×620，经典面板仍执行原来的位置/大小重置。尺寸弹窗只在已启用的场景面板中挂载。

尺寸弹窗宽256，底色为普通白色卡片。尺寸输入、加减、保存、预设、删除和底部两个操作都使用项目现有普通 DOM 控件及表单共享样式；不再引用任何 WebGL 玻璃库或画布背景。两列等宽、间隔8px、各高36，填满表单横向空间。「恢复默认」执行当前默认预设的重置，「完成」关闭弹窗，二者都是可见文字按钮，指针与键盘走同一个原生 click。

数字输入在离开输入框或按Enter时应用；加减按钮每次20点。预设统一按顺序显示「预设1、预设2……」，前三个内置尺寸依次为480×540、640×620、900×720，自定义预设接在其后。预设紧凑换行排列，具体宽高放在按钮title提示中。可保存当前实际窗口尺寸，按尺寸去重、本机持久化，支持调用和删除；删除后界面按现有顺序重新编号，不迁移已有尺寸数据。支持普通滚轮/触摸滚动、Esc关闭；收起工作台也会关闭弹窗。

数值调节与重开恢复不使用screen.width或1400px作为宽度上限，高度仍受宿主1000px上限约束。预设保存在本机localStorage，不同步到其他设备。安装包只含编译后的运行代码与必要资源，不附原始TypeScript、源码压缩包或source map。

边框为网页内半透明视觉效果，不承诺原生窗口背景透景；原生WebView透明度与背后场景是否合成取决于宿主。角部收到指针序列时使用公开mn.size缩放，不能强制抢占宿主原生拖动。顶部交互布局是用户明确指定的取舍；宿主仍有顶部拖动区，公开接口不能关闭四周拖动或设置交互豁免区。桌面点击通过不能证明原生触摸不被拦截，需真机确认。场景自动隐藏列表继续点按展开/收起，经典侧滑保持。


## 打开与保存

手写入口不定位、不聚焦原卡片，也不切换学习集。宿主拒绝、资源加载失败或超时在原工作台提示，不自动重发写请求。整卡渲染可能较慢，宿主打开请求允许 30 秒，原生业务请求等待上限为 60 秒。读取版本后、提交打开请求前再次核对场景；保存后读取批注前也核对场景。超时不等于未打开，用户应先检查是否已有书写窗口。

原生业务只按错题记录解析目标身份，返回原题 `noteid`，不执行导航。书写目标不取当前焦点卡。场景页面以 JSON 序列化请求体，读取新鲜版本后直接调用公开批注接口。文档明确不传 practice 也能打开；因此不把来源学习集必须当前打开或脑图文档同步开关作为插件侧前置条件。仅 `editorOpened === true` 表示确认打开，不表示已保存。

用户需在原生编辑器中明确保存；取消不视为保存。插件互斥只覆盖打开请求，成功、失败或超时后都释放，不依赖普通批注是否发出 practice 关闭事件。编辑器仍占用时由宿主的 ANNOTATION_UNAVAILABLE 拒绝，插件不自行认定关闭，也不自动重发。

清单声明 practice 与 comments。practice 保存事件重读批注并按 commentId 核对；普通批注的 comments 变化事件也按对应题卡重读并刷新详情。刷新不改变掌握等级或复习计划。读取失败记日志；场景断开或关闭面板时释放面板与页面状态。

## 场景详情预览

场景与经典面板共用原有卡片 HTML 内容及缩放控制器。场景使用安装包内的 `/pkg/web-dist/preview.html` 同源页面，不使用 srcDoc；样式通过预览页外部样式表的 CSSOM 应用，手写解码及绘制代码在构建期生成独立脚本，不执行卡片 HTML 自带脚本或事件属性。恢复评论展开/折叠、状态记忆、复习默认展开数量、绑定手写双击切换与卡片缩放。经典面板保留原来的 srcDoc 路径。

卡片内嵌图片使用公开的 `panel.putMedia(key, data, type)` 交给宿主，通过 `/media/<key>` 显示；不将 Data URI、Blob 或本地文件 URL 作为场景图片来源。切换内容、取消加载或卸载组件时删除对应媒体键；传递前重新核对场景状态。失败显示错误与重试。

OCR 题目准备与 HTML 导出预览复用同源预览页；截图克隆同步 CSSOM，避免布局丢失。OCR 原图、历史图片与 PDF 分页预览也使用媒体缓存。PDF 文件只允许读取插件自身临时缓存中的分页预览图片，不提供任意本地文件读取。自定义遮罩上传先读取文件，再通过媒体缓存显示并缩小；保存格式沿用原来的 JPEG 数据。PDF 生成、保存与原有业务后端保持原流程。

参见 [面板之外：媒体缓存](https://dev.marginnote.com.cn/zh/jsaddon)、[UI 控制](https://dev.marginnote.com.cn/zh/ui) 与 [安全策略](https://dev.marginnote.com.cn/zh/network)。

笔迹由宿主保存，本次不迁移错题数据，不修改掌握等级或复习计划。

## 兼容与验证

桌面自动化覆盖版本门限、场景确认、经典回退、异步消息、题目身份、无导航调用、请求不含 practice，以及关闭保存事件。b19 真机日志已确认场景面板启用和应用渲染；旧实现失败于手写前的定位流程，切换学习集时面板丢失。b20 已去掉整个前置流程。普通批注模式在当前设备的编辑器打开、关闭事件和笔迹保存仍需验收，桌面模拟通过不代表这些行为已验证。
