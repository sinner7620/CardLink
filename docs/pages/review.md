## 复习完成烟花（2026-11-02）

复习冻结队列从最后一题推进到结算时，使用本地打包的 [canvas-confetti Realistic Look](https://www.kirilv.com/canvas-confetti/) 五段彩纸效果，共 200 粒，与原生「本次复习结果」弹窗一同触发。固定曲线与 FSRS 复用相同完成入口；跳过末题也算队列结束，不代表所有题目都已评分。中途退出即使显示结果弹窗也不播放，做题模式、逐题反馈、数据刷新和评分保存失败均不触发。

「个性设置 → 待复习设置 → 复习完成烟花」默认开启，可关闭且不影响结果弹窗。系统减少动态效果优先。透明、不可交互的插件画布在复习开始时隐藏预加载，仅结算播放时显示，避免加载白底遮住题目。不等待画布来延迟结算；无法预加载或结束时尚未就绪则跳过烟花。弹窗关闭、最多 5 秒、模式挂起或丢弃会清理画布，旧回调不能清理新会话的画布。

烟花复用悬浮菜单的原生透明容器 `createWindowSurface`，优先挂到悬浮球所在宿主窗口；无悬浮球时使用当前插件窗口。容器与 Canvas WebView 均不接收触摸，不添加遮罩或面板底色。HTML、Canvas、WebView 与内部子视图背景全部清为透明，加载完成及播放前重新清理宿主可能重建的白色底层。保留隐藏预加载，结算时将原生容器置前并显示，退出时移除容器及画布。

桌面可验证透明属性、原生容器层级、开关及完成触发；真实 MarginNote 的背景合成、原生 `UIAlertView` 层级和背景变暗仍未设备验证。画布不修改宿主窗口级别，不保证粒子覆盖原生弹窗；系统结果弹窗自身的暗化也不由烟花层移除。

## 本轮反馈回看与恢复窗口（2026-11-02）

当前交互以 [做题与复习流程](../design/practice-review-flow.md) 为准。已在本轮反馈的题切走返回时仍正常打开批注，保留上次等级、错因及作答身份的成功快照，不弹反馈、不重复评分。宿主下一题／做完了保存后切题并打开下一题窗口。做题的“复习反馈”或复习序号菜单的“查看／修改本题反馈”可在书写时手动展开，点击等级才重新提交，并等待当前批注保存；本轮状态随退出释放，新一轮不继承。重新选择当前题可新建批注，不自动把旧等级写入新作答，只有主动反馈才更改结果。

批注做题未主动选择等级时，点宿主“下一题／做完了”保存后默认提交原生“会了”，成功后同时记录本份作答“已对答案”，再切题开窗或末题结算，不弹反馈框。此默认记录按用户约定生成，不要求实际打开答案窗口；判定失败不记已对答案，保留本题供重试。下一轮打开省略旧批注 ID 请求新作答，不继承上份笔迹的本地反馈状态；实际新建仍须宿主遵守接口契约。已有错题、继续旧作答也遵守此规则；默认判定不写 CardLink 错题反馈、复习历史和计划，宿主原生判定标签由宿主接口维护。只有用户主动打开反馈并选择等级才标错或更新原错题；只打开反馈区、只选择错因不算评分。复习模式仍要求等级反馈。

反馈区有窗口令牌时提供“批注窗口已关闭？恢复操作”，仍先查关闭回执，未知状态只允许用户显式确认；收到关闭回执后保留“重新打开批注窗口”。横排恢复入口独占整行，避免双栏截断。脑图做题遇已有错题也可直接下一题或末题结算，不改已有历史或计划；主动反馈仍更新原记录。批注做题工具条不显示下一题，只保留标错／反馈主动作；其他模式的下一题按钮不移除。

以上由桌面原生控件模拟和行为测试验证；MarginNote 实际触控、窗口合成及保存回执仍需设备验收。

### MN5 折叠优先（b75、b76）

MN5 场景模式下，脑图书写入口的做题与复习改为折叠优先：进入题目之前先收起题卡分支，确认收起后再定位。方案见 [MN5 场景模式的折叠优先脑图书写](../design/mn5-mindmap-fold-practice.md)。

适用范围按**当前题的实际绑定**判断，不看学习集的全局绑定：只有场景面板已授权、答案为该题直接子卡、且整支可安全收起时才折叠。以下情形一律沿用原有答案遮盖，并在本轮首次遇到可折叠的直接子卡题时提示一次回退原因：直接子卡下还有下层卡片（不遍历全图即无法证明整支可隐藏，因此保守回退）、分支混有非答案卡片（混合绑定且索引无法证明整支都是答案）、读不到 `mindmapBranchClose`、画布与字段不一致、场景能力不可用。纯答案脑图绑定、混合绑定的本题没有直接子卡答案、批注或手写书写模式都保持原行为。

写入只由已授权的场景面板调用官方 SDK `mn.api('/notes/fold', …)`（`POST`，`{ noteIds: [题卡], folded, confirm: true }`）。该接口请求体没有 `topicid`，因此面板在写入前用刚读到的 `/ui-state` 的 `topicid` 核对目标题卡的学习集：缺少学习集、读不到当前学习集或与目标不一致时一次都不写，回执里带出场景实际学习集供诊断。JSB 侧按题卡 ID 读 `mindmapBranchClose`，目标状态已满足时不写入，写入后重新读回；响应里的 `folded` / `changed` 只作诊断，不作为成功依据。读回期间每次重试前都重新核对访问代次、当前学习集与场景窗口会话，任一变化即停止确认。常驻监测只读当前题卡与当前画布，不做学习集级扫描。

宿主折叠字段读回为收起时，当前题停止绘制答案遮盖，即使模型节点列表仍保留答案子卡的旧坐标。若检测到答案子卡的原生视图仍附着且可见，则继续遮盖，等下次同步时再判断。分支展开、字段读不到或原生折叠失败时，使用原有遮盖。模型节点列表用于放置遮盖，选中节点视图列表用于识别仍附着的子卡视图。

进入题目时先尝试折叠，再定位并读回。定位或手动展开恢复分支时先补遮盖，再尝试重新折叠。用户主动查看答案时按现有设置展开分支或打开答案窗口。

切题、退出做题或复习、队列结束时，CardLink 停止遮盖同步并清理会话遮盖。题卡保留当前的折叠状态，主动查看答案后展开的分支也保持展开。

折叠与主动展开串行执行，并核对题卡 ID、场景窗口、学习集及访问代次。公开场景事件没有分支绘制前的通知，现有约 160 毫秒的同步节奏无法保证零闪现。折叠字段和真实视图不同步时的画面表现仍需 MN5 真机核对。

诊断按需写进运行日志（调试模式）与控制台：`enter.applied`／`enter.fallback`、`settle.applied`／`settle.contradicted`、`monitor.refolded`／`monitor.blocked`、`reveal.fallback` 等，附 `folded=…`、`visible=已见子卡/子卡数`、`detached=`、`source=selection-view|none`、`canvas=ready|notReady`、`target=attached|unknown` 与 `outcome=`。下一次设备日志据此可判断"字段已收起但画面未确认"出现在哪一步。

### 批注书写

批注卡片模式使用当前页面筛选后的队列和顺序，开始后冻结该队列，直接按题卡 ID 打开第一题的整卡批注。此模式将原复习工具条放入 MN Utils 悬浮球展开区域，保留序号进度环、上下切题、退出和来源分类索引，增加当前队列题目的答案查找和继续书写入口。复习期间悬浮条保持展开，退出复习后恢复悬浮球。

原生批注使用当前模板配置的练习作答模式，点击编辑器「下一题／做完了」保存关闭后，由 CardLink 接续反馈与切题。复习模式展开等级区；批注做题未主动选择等级时默认原生会了并推进，不自动展开反馈区。题名与分类来源复用同一透明顶部区域，与侧栏共用底板；下方更白的圆角列表只显示等级、跳过及必要的恢复入口，标题不放在列表内部。顶部显示当前待评价题目的名称（没有新增笔迹、saved=false 也允许评价）。固定曲线三档、FSRS 四档，复用原保存接口；保存成功后才进入下一题，最后一题评价后显示总结。复习未选等级时停留当前题，可继续书写；做题未选等级时保存后按默认会了推进。跳过不保存评分。取消或直接关闭而未点完成时返回当前题；有待执行导航时仍以关闭回执确认编辑器已释放。每次从做题入口普通打开书写时不指定旧批注 ID，但这不等同于强制宿主新建空白纸；宿主返回身份匹配的 CardLink 作答时仍可能复用。历史作答窗口的“从当前批注继续”会明确传入当前选中的批注 ID。本轮 ID 用于绑定反馈，随会话结束释放，批注由宿主持久化；默认会了不清空笔迹。

批注正在打开或提交评分时，切题和重复评分被锁定；编辑时可以选择待跳转目标，需由批注窗口自身的完成按钮保存关闭后执行。点击悬浮条下一题立即展开等级区，上方为当前待评价题名；编辑器还打开时可预选等级（含跳过），仅在保存关闭后提交并推进，取消未保存会清除预选。未预选时保存关闭后保留等级区等待点击。明确拒绝打开后可重试；打开结果不确定时不自动重发，允许退出复习并核查宿主窗口。当前版本的自动全屏尚未实现：公开接口未列出全屏参数，批注按钮模式及原生悬浮层显示也仍需设备验收，不能以自动化测试替代。

进入冻结队列并定位原题后，若绑定为直接子卡片或混合匹配且当前卡片颜色属于题目颜色，自动遮挡当前题目的直接子卡片答案。切题重新遮挡新题，退出清除遮挡；查找答案仍遵循“窗口展示／揭开子卡片”的设置。

悬浮条下一题的等级反馈与答案胶囊共用已有复测保存接口。成功提交后通知工作台重新读取待复习队列、复测历史和下次复习时间，再进入下一题；跳过不保存、不通知，失败停留原题。未打开或未就绪的面板不阻断复测提交，下次显示时按既有版本检查读取数据。本次复习的冻结队列保留已完成题供回看，待复习页面按更新后的复习计划重新分类，两者口径不同。

复习小横条可自由拖动并停留，本次复习切题或重新挂载后保留位置，来源和评分下拉框跟随横条；详情按钮及面板已移除。来源以紧凑的 › 逐级连接，展开、收起及下拉开合使用原生动画，减少动态效果时直接切换。脑图书写模式的答案窗口顶部居中显示红、橙、绿三圆点胶囊，仅在窗口对应当前队列题目时显示。批注卡片模式关闭答案窗口内的等级胶囊和评分点击面，统一使用悬浮条等级区评分。点击后整组横向展开为「不会／不熟／掌握」，再点击任一等级立即记录当前题目的复测结果。点击外部收起胶囊，并保留该区域原本操作。关闭答案窗口、换题或退出复习会恢复收起状态；减少动态效果设置下直接切换形态。窄窗口将胶囊放在顶部第二行，同时给正文留出空间，避免与窗口操作按钮重叠。保存成功后关闭答案窗口并进入下一题；最后一题显示本次复习报告。保存期间禁止重复提交和切题，失败时留在原题重试。

## 验收

原生悬浮条图标和答案窗口等级胶囊在容器挂载后加载绘制页，加载完成后同步最新状态。重新挂载时检查绘制内容，缺失时恢复一次；关闭后的旧回调不再更新控件。冷启动首次进入、切题和关闭后重新打开均应显示完整控件，等级胶囊只在答案对应当前复习题时出现。

切页即时（不随到期数线性变慢）；复测后队列与倒计时实时更新；跨页目标可见、居中且有强调反馈。

今日到期的随机补充选项紧跟「随机补充：」右侧，窄屏按可用空间自然换行。四入口的选中块使用柔和阴影并避免在导航边界截断；展开全部与复习模式恢复独立按钮底色、边框与按压反馈，减少动态效果设置下关闭按压缩放。


## FSRS 智能复习（调试）

调试设置的曲线开关决定待复习页及原生复习会话使用哪套调度。关闭调试始终采用固定曲线，FSRS 模块在门闸通过后动态初始化，独立存储不读取、不写入。源码随安装包分发，但不在普通模式执行调度或迁移。

FSRS 的四档为本次反馈：不会（错误或依赖提示）、不熟（独立正确但吃力）、良好（独立正确且顺畅）、掌握（独立轻松）。最后一档不会结束自动复习。列表显示最近反馈而非永久掌握等级。总览和错题浏览仍是固定曲线档案，智能模式中有明确提示，原等级写入入口被拦截。

`fsrs-domain.ts` 封装 ts-fsrs 5.4.2 / FSRS-6；`fsrs-store.ts` 负责独立版本化存储；`fsrs-service.ts` 负责门闸、一次性迁入及桥接。独立键为 `mn4-answer-matcher.fsrs.v1`，备份为 CardLink/backups/FSRS智能复习备份.json。共享题目身份与内容，评分不写固定等级、标签、到期日或历史。

首次启用只复制到期日、旧等级参考与结束状态（迁为暂停），不复制含义不确定的旧评分，也不估算虚假的稳定性/难度。首个真实反馈建立记忆状态。每题仅迁入一次，切回原算法恢复其原进度；新增题在下次进入智能复习时迁入。设置修改在下一次评分生效，不重算已有日期。

错因支持六项多选与 500 字备注，仅用于记录和筛选，不改变 FSRS 数学参数。可补改历史错因。只能更正末次评分：使用该次原始时间、参数及前状态重新计算，不增加次数；跨引擎版本不重算。修订号防止过期页面覆盖，事件 ID 防止重复提交。

原生复习和答案窗口使用四个反馈按钮。不会时可选错因，备注在面板历史补填。暂停/恢复仅作用于智能进度。会话中禁止切换算法，智能会话中禁止关闭调试。未做知识点迁移推断、同标签联动、BKT 或考前调度。


### b85 界面复用

两套算法均渲染现有 DueReviewList，保持原状态导航、分类筛选、展开题目、答案预览、历史时间轴及复习模式布局。FsrsReview 仅作为数据与操作适配器，无独立页面或样式；fsrsQueueRecord 将智能进度投影为队列视图模型，不回写固定记录。智能模式使用四档最近反馈筛选，旧迁入题显示待反馈，已结束栏对应智能暂停。错因和末次更正折叠于历史区域。临时从逾期池补充今日队列在智能界面内独立保存，不改变固定今日队列。

智能设置移至设置 → 错题管理原复习间隔位置，通过 fsrsGetOptions 只读取参数，不为设置页加载全部题目。固定模式保持原天数编辑。智能内容读取继续走只读 fsrsContent。


### 入口范围

FSRS 模式中固定间隔保存命令拒绝写入；错题本的旧等级修改控件只读，详情复习按钮跳转智能队列。总览和导出的历史等级统计仍以固定档案为准，不是 FSRS 记忆模型指标。原生侧边的“标记错题”负责题目入库，既有题的固定反馈受门闸保护，并未改为四档 FSRS 入口；智能反馈应使用待复习/原生复习会话。错题本提示放在原有数量栏，不能插入额外块推移搜索布局。

做题与复习的脑图、批注书写统一使用 MN Utils 悬浮球展开区的同一套工具条。顺序为插件入口、序号进度环、上一题、下一题／对号／标记、查找答案、分类、退出。插件入口直接打开 CardLink；退出使用 SF rectangle.portrait.and.arrow.right 图标。复习脑图显示下一题箭头，复习批注显示对号；批注做题显示标记旗帜；脑图做题保留下一题并增加独立标记旗帜。每次打开工具条根据当前位置的最近边缘选择方向，上／下横排、左／右竖排；点击展开时也重新检查稳定主控区的位置。拖动接近上／下边缘改为横排，接近左／右边缘改为竖排，保留当前队列、题目和分类状态，无旋转按钮。序号可选择题目，重新选择当前题可继续书写。

批注工具条在书写中选择上一题、指定题目、分类题目或退出时，只记录待执行操作，并提示点击批注窗口右上角“完成”保存关闭后继续。可重新选择目标题，以最后一次选择为准；取消且未保存会清除待操作。无待跳转操作时，宿主下一题/完成进入反馈，无新增笔迹也可以评价。工具条不主动调用打开批注接口来关闭当前编辑器。

所有书写模式沿用原批注工具条的材质样式（quick-menu-surface.ts）：78% 浅灰底、灰蓝描边与紧凑阴影，选题列表为 58% 白色圆角面板。横排点击分类后，完整来源路径追加在全部主控按钮右侧；包括退出在内的所有按钮位置和宽度保持不变，切题造成的名称长短变化只影响分类区宽度。可用右侧空间不足时，分类区以横向滚动展示。横排主控初次放置及拖动限位预留最小可用分类视口，展开后不会为容纳文字重新向左贴边。竖排分类根据左右空间自动选择展开侧，右侧贴边时向左显示；横排选题/反馈列表根据上下空间选择展开方向，底部时向上显示。主控位置在这些详情面板展开收起时保持不动。常规控件为 44 点，进度环为 30 点非交互 WebView，序号为原生文字。布局与分类开合采用 0.2 秒原生动画，尊重减少动态效果。分类收起时旧来源和列表淡出，底板与按钮同步收缩。上一题、下一题、对号、查找和分类使用保留的 SF Symbols，标记、退出、历史和收起分类也统一使用 SF Symbols 的透明 PNG（flag、rectangle.portrait.and.arrow.right、clock.arrow.trianglehead.counterclockwise.rotate.90、sidebar.left）。横排工具条底板只覆盖工具行且不绘制阴影，下拉列表使用自身背景，外框透明。分类路径展开后保持，按钮变为收起图标；点击外部仅关闭下拉列表，主动收起才折叠路径。底板与图标在同一个动画事务中归位。竖排点击外部收起分类；未预选等级的反馈可再次点击主动作或外部收起，已预选或正在提交时保留。工具条在打开插件时保持，退出会话才恢复悬浮球。


复习查答案显式使用队列题目的来源学习集和脑图范围解析绑定，包括索引刷新后重试。子卡绑定查直接子卡，答案脑图绑定使用对应目标；批注模式始终在答案窗口显示，不在批注编辑器背后解除脑图子卡遮盖。
选题前的普通快捷区保留原有 94% 底板；进入做题或复习后统一使用上述工具条样式。

窗口关闭状态：按复习会话令牌和宿主返回的卡片身份匹配 practice 关闭事件，兼容卡片 ID 大小写。转发失败仍保留关闭回执；工具条切题或退出前先查询并补偿同步。关闭回执表明窗口已经关闭时直接继续操作。正常书写尚无关闭回执时保留待操作，不自动弹出状态确认。公开文档没有可靠的编辑器可见状态字段；窗口确已关闭而操作未继续时，主动点击等级区底部“批注窗口已关闭？恢复操作”，才出现恢复确认。取消恢复保留原会话，确认关闭后解除占用并继续；这不是正常切题的前置步骤。该恢复只解除会话占用，不伪造已保存笔迹或 commentId。comments 更新本身不视为关闭。

批注复习期间隐藏工作台、切换学习集或关闭场景面板外观时，保留同一个场景运行会话及关闭回执。场景检查暂时失败只暂停新业务，不阻断已有批注的关闭回执和状态查询；再次打开批注仍检查宿主真实场景状态，确认恢复后继续。插件停用或场景断开仍销毁会话并拒绝迟到回执，普通非复习场景保持原有关闭和回退行为。

做题队列重新展开时，使用当前做题会话保存的题目 ID 展开祖先分类，并按最终窗口高度将对应行滚动至视口中间；结束做题或切换学习集时清除当前位置。不重新触发脑图定位。


批注进度环的 WebView 在 44×44 点序号按钮内居中，独立限制为 30×30 点圆形区域；WebView 与内部滚动视图均设透明、不接收触摸、不滚动，序号保留原生文字。加载期间只保留最新状态，横竖切换复用已加载页面，退出或重挂载时暂停旧回调。此适配避免恢复整条横向 WebView；宿主实际透明合成仍需真机确认。


批注复习悬浮窗按宿主窗口尺寸计算可用内容区（扣除边缘和底板留白）。空间不足时七个按钮沿当前方向均分可用长度，分类和等级列表按剩余宽高布局，内容超过视口时滚动显示。正常空间仍使用 44 点控件。分类列表在拖动重挂载、横竖切换及重新打开同一分类后恢复该分类滚动位置；不同分类独立记录，视口变大时将偏移限制在有效范围，记录随复习会话释放。

## 切题性能与脑图生命周期

复习条在同一宿主与方向下复用主视图、按钮及进度页面，忙碌状态只更新控件。批注标题/列表内容未变化时也复用；目录、题名或方向变化才调整对应布局。相同圆环状态不重复提交脚本，切题不再等待固定动画延时。

批注打开成功后后台预读下一题的 comments revision，打开下一题时保留一次写前场景确认；评论事件使预读失效。只缓存少量版本号，明确 COMMENT_CHANGED 才刷新并重试一次，未知打开结果不重试。复测仍成功保存后才推进，不将通知失败或版本缓存当作评分成功。

退出脑图移除复习条、展开面板和入口，保留队列、当前题和方向。重新打开脑图自动恢复界面；已关闭脑图的延迟恢复回调无效，关闭期间收到的批注事件不重建界面。恢复不主动重开编辑器，也不增加跨插件重启保存会话。

预览缩放与惯性由系统 WebView/浏览器处理。展开的做题／复习工具条拖动时收拢为预览，暂停约 280ms 显示当前位置的展开轮廓，继续移动恢复紧凑预览，松手在释放位置自适应展开并按窗口限位；普通悬浮球及选题／摘题快捷区仍在松手时就近吸附边缘。

做题通过同一会话的 purpose 区分：批注主动作是标记错题，脑图则单设标记按钮，只有用户主动点击才出现不会／不熟／掌握选择，脑图书写保存成功后自动下一题，批注书写仍等待宿主完成作答；切题或批注完成不会自动弹出反馈或写入错题记录。非错题的序号底色为白色，已入库错题读取当前等级显示红／橙／绿，进度环随之为白色。主动标记调用现有错题保存接口（既有题遵循当前算法门闸）。脑图做题的下一题记本轮完成并推进，独立标记按钮脑图书写保存成功后自动下一题，批注书写仍等待宿主完成作答；也可通过序号、分类和上一题导航，批注由宿主右上角下一题／做完了保存关闭后推进。复习评分与调度契约保持不变。

首次进入做题／复习时按悬浮球当前位置自动选择横排或竖排；工具条首次渲染保留球体大小的外框，随后动画展开到最终布局，减少动态效果时直接切换。完成或退出会话后悬浮球按当前位置就近贴边并保存位置。做题标记按钮读取实际错题状态：无记录显示旗帜，已有等级记录显示对号及“复习反馈”；选择等级复用既有复测保存逻辑，更新历史和计划，脑图书写随后自动下一题，脑图下一题仍独立。

切题期间按钮只锁定操作，不因导航忙碌改变透明度；第一题的上一题仍显示不可用状态。序号标签保持挂载在圆环上方，数字、颜色与图标状态原位更新。分类路径未变时复用来源视图并更新层级选中状态；实际换路径才重建，分类列表按需要更新。

## 本轮作答与原生历史摘要

每次从书写入口打开均请求新建，不传 commentId；只有历史窗口明确继续原生练习批注时才指定 ID。每轮启动批注做题／复习先检测宿主判定接口与模板对 CardLink 的 tagPrefix/reasons 配置。缺配置或检测失败提示原因并停止，不创建会话、不打开普通批注、不修改旧题反馈。切题不重复检测，重新开始重新检测。只有模板和判定接口可用时才采用原生练习批注，反馈提交 practice-verdict。普通旧批注保留查看，不能通过统一批注模式继续。脑图书写和新手写会话不要求这份作答判定模板配置。错因清单用于工具条内的主要错因区域：先选可选错因，再点等级提交；不选或取消错因仍可保存等级。原生提交 self 与 reason，掌握清除 reason。

竖排展开列表底部不超过工具条底部，超出部分滚动。全局颜色在答案绑定管理展开后的表格上方配置，与每条脑图的局部颜色合并，始终作用于所有脑图。

## 历史作答窗口

批注书写的查找答案右侧增加历史作答入口。列出该题、该学习集的旧原生练习批注，以及有 CardLink 本地作答身份的新普通批注，按创建时间编号并倒序展示；左侧显示日期、次数、反馈及错因，右侧只渲染选中的作答评论。中间短竖条点击切换列表显隐，左右滑动也可切换。详情加载不重置当前选择，过期的跨题读取不会打开窗口，退出复习/做题关闭窗口。

每次新开始做题和复习都重新建立本轮批注身份，同轮返回也新建批注；继续旧批注须从历史窗口明确选择。实际成功显示答案后，CardLink 记录本轮已查看答案状态；保存批注时关联 commentId，历史窗口显示已查看/未查看，旧记录显示未记录。本地查看状态及普通批注的作答索引/反馈不跨设备同步；在其他设备上原生批注仍存在，但本地历史不保证识别这些普通批注。当前公开 practice-verdict 仅支持 self 与 reason，没有已对答案字段或自定义原生折叠摘要接口，因此此项只显示于 CardLink 历史窗口，不声称已写入宿主折叠行。成功打开答案不代表用户实际完成了人工核对。

模板缺少原生判定配置时，即使存在旧未反馈作答也不另开普通批注、不改判旧题。原生反馈必须收到持久化成功确认后才推进；失败保留本题供重试，不自动切换模式或重开窗口。原生判定成功而本地复习保存失败，重试相同判定不重复写入。调试日志记录能力、配置、被阻止的模式与请求身份。

待复习的分类工具栏位于页面滚动容器内，随页面滚到顶部后粘在主导航下方；筛选和排序以下拉覆盖列表，打开时不改变下方内容位置。横向做题工具栏与竖向共用外层背景及较亮的内嵌列表，切换分类不会改变下拉横向锚点和整体宽度。

历史作答窗口默认 680 × 500（窄窗口按可用空间收缩），标题左侧区域使用原生手势拖动并关闭位置补间动画；右下角支持拖动缩放和方向键微调，移除右上角“尺寸”入口。圆形列表开关位于列表外侧、详情区左上角，折叠后留在窗口左上角供恢复。历史列表选中后可点“从当前批注继续”，明确打开这一条批注；缺少 commentId 的旧记录不能继续。当前会话内调整生效，重新打开恢复默认尺寸。

历史续写前的新批注不再一律要求反馈。选择历史后，当前空白新板在下一题关闭回执确认后直接进入选中的历史；当前新板已保存内容则询问是否保存，选择保存须先反馈，选择丢弃只移除确认属于本次新建的批注，不写复习成绩。宿主公开接口只在编辑器关闭时提供 saved/commentId，不能读取未保存笔迹，因此保存询问在宿主保存关闭后出现；丢弃采用批注删除并读回确认，失败保留任务。历史续写后的复习反馈要求不变。

做题和复习悬浮条的反馈等级仅对已有错题显示下一次间隔（+x天），普通题不附加。固定曲线按保存时的等级、次数及自定义曲线推算，完成条件显示“结束”；智能复习显示各等级的预估天数。答案窗口的反馈胶囊仅显示等级，不附加日期或天数。

## 官方反馈与新作答

批注模式采用模板配置的原生练习作答：打开时携带 expectedRevision、practice.topic、advance 和 confirm，新建省略 commentId，历史显式继续才指定 ID。题目由冻结队列提供。新建响应明确复用旧纸仍按实际响应报错；不替用户判定旧作答。

新建响应若明确 continued=true 或返回已有批注 ID，会提示误开旧批注；该编辑器的关闭事件不作为新作答保存、评分或自动下一题。用户需先关闭编辑器。不自动重开编辑器；宿主没有提供明确身份回执时，不能仅靠桌面测试证明它确实新建。

悬浮球与展开工具条的拖动使用禁用位置补间的原生 frame 更新。复习／做题拖动只移动预览，不重排真实按钮；最近边缘的方向和距离缓冲保持预览稳定。松手只运行一次预览外壳展开，真实控件先完成隐藏布局，动画结束后原位交接，避免布局提交再启动第二次动画。取消恢复原位，重新拖动或关闭使旧停留计时器和完成回调失效。普通球的松手吸边动画保留。

分类区域采用完整名称和原生横向滚动，路径切换后将偏移限制在新路径内容范围。外层窗口以稳定主控区为锚点，分类宽度不再参与贴边计算；向左或向上展开面板时通过局部坐标原点保留主控的屏幕位置与点击区域。


## 筛选、按钮与批注关闭反馈（b65）

默认队列不限制来源和等级，筛选面板内的来源与等级均呈中性状态。第一次点击来源或等级就仅选择该项，进入自定义筛选；随后点击可增减选项，重置回到默认。筛选图标在展开或存在自定义选择时为主题蓝；排序与展开图标采用同样的蓝色点击反馈，不加选中底色。筛选顶部操作栏为不透明底色。开始复习使用完整的主题蓝白字按钮，不再裁用尺寸窗口的独立 WebGL footer。

每轮模板判定配置检测保持一次。选择反馈等级时先补查保留的关闭回执；查到关闭就继续处理。未知状态不视为仍在书写，不再自动提示“请点批注窗口完成”。手动恢复入口保留，明确的同步错误仍显示错误信息。

首次安装不显示旧错题迁移确认、不自动执行标签迁移；旧面板的迁移确认命令已停用，不改写标签。手动整理入口保持原有用户主动触发方式。注册卡片菜单的中文名称为“答案／标错”，命令 ID 不变。


### b66 跟进

等级筛选操作栏固定在筛选浮层顶部；仅来源分类区独立滚动并裁切，不再让分类滚动到操作栏下面。操作栏有不透明背景并正常命中点击。

历史“从当前批注继续”在判断忙碌前补查关闭回执，收到回执后留在当前题打开所选批注，不自动跳题。没有回执时可在该入口显式确认窗口已关闭并恢复；未知状态不作为已关闭的证明。

插件内批注的工具条退出与等级反馈共用画布的导出、图片保存和折叠事务；先补收已有关闭回执，没有回执且窗口仍在时导出最新笔画后保存。退出成功才结束会话，保存失败保留当前题；做题反馈在保存成功后写入等级，避免保存失败却先改变成绩。

拖动展开结束交接时暂时禁用 UIView 继承动画，并清理外壳、容器及按钮的残留 position／bounds 动画，随后在同一段布局中恢复真实外框。实际触控帧率与闪动仍需设备验收。


## 手写会话与选题反馈（b67）

做题／复习的“手写会话”选择入口暂时隐藏，内部焦点卡专用层实现保留。用户提供的 2026-11-01 b73 插件日志显示，宿主 5.1.0、接口 0.93 的会话及分层能力均返回 `ready:false`、`canSwitch:false`。内部实现仍在运行时读取 `/capabilities`、`/guide` 和 `/writing/capabilities`，对应会话及分层能力未就绪时提示并停止。单题准备清单、会话和尝试使用独立 requestId；未知结果保留原请求，重试查询同一身份，不重复新建。

切题、评分、退出先保存当前专用层笔迹，校验快照已确认且仍为当前快照、宿主允许切题，再退出尝试。之后才写 CardLink 复习成绩或切换目标；跨学习集先结束上一题会话，再沿既有定位流程导航。会话结束需读回当前运行身份已释放。该模式不调用 annotation-editor，不生成普通批注，也不要求原生 practice-verdict。每道题使用独立的宿主运行记录，等级仍由 CardLink 原有算法管理。

当前没有留白载体、跨重启恢复界面或手写会话历史浏览入口；不把普通批注历史当作专用层历史。设备能力、保存语义与真实触控仍需真机验收。

批注分类列表分别标记“当前”和“待切换”，使用主题蓝显示当前或待选题；实际保存关闭前不把目标当作已经打开。待切题目标加入详情重绘状态，点击后立刻更新。状态查询有关闭回执时直接执行；没有回执时提示“若仍打开，请点右上角保存；若已关闭，请在反馈区恢复”，不把未知状态断言为仍在书写。


## 非会话入口的标记和反馈错因（b68）

普通标记或固定曲线单题／批量反馈在提交不会／不熟时先选择主要错因，再写等级；支持跳过错因保存，取消则不写本次等级。会话工具条从 b69 起使用反馈区内选择。卡片菜单已改为等级即时保存与按需展开错因，外部关闭保留已保存等级；卡片侧边三级快捷反馈及详情侧边单项改级暂不弹错因，仅保存等级并保留已有错因。批量复习的原弹窗选择仍应用到本批题目。

原生批注从本轮模板读取选项，原生反馈提交 reason，固定曲线历史同时存储 key 与 label。宿主必须回传相同错因，失败保留当前题；重试沿用选择，不再次询问。旧普通批注查看契约不变。

脑图／手写及非会话标记使用六项内置错因。固定历史通过可选 errorReason 显示，旧历史不补填或推测错因，不改变复习调度。智能工具条单选内置键，自定义模板错因写入备注；网页智能复习保留多选与备注，不会／不熟均可填写且保持原评级。
