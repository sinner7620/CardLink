# 功能页：待复习
## 入口
main.jsx `DueReviewList`。
## 功能
今日/已逾期/未来/已结束四态队列、复测评价（不会/不熟/掌握，实时显示下次日期）、完整原题懒加载（默认收起，批量展开只读取轻量原题内容；失败可单题重试）、答案查看缩放、历史时间线。顶栏下方悬浮条直接复用设置页的 `settingsCapsule` 和 `settingsCapsuleSlider`。两页浮条挂在同一个 main 定位容器，居中、距顶栏 10px、高 48px、最大宽 640px，窄窗两侧各留 12px。四个状态入口与右侧筛选、展开全部、复习模式和题目数共用一层胶囊背景与阴影；交汇处为同一表面，不再叠加独立底色或 SVG 融合层。继续缩窄时右侧仅保留菜单图标与题目数；菜单内直接同排显示分类、等级选择和展开／收起全部、复习模式操作，宽度由内容决定。题目数与右边框留有间距。列表上方不重复显示队列名称和说明，页面也不重复显示四张统计卡。状态滑块采用参考胶囊的 0.45 秒缓动，文字颜色采用 0.28 秒缓动和 0.06 秒延迟。从错题详情的剩余天数胶囊进入时，目标题目滚动到队列视口中央并短时高亮。
## 边界
- 原题只为已展开记录请求（最多双并发）；手动补入今日队列由原生完整错题库选择并按本机日期保存，分页加载及刷新不改变该队列，次日自动清空
## 验收
切页即时（不随到期数线性变慢）；复测后队列与倒计时实时更新；跨页目标可见、居中且有强调反馈。

## 待复习控件调整（2026-09-27）

今日到期的随机补充选项紧跟「随机补充：」右侧，窄屏按可用空间自然换行。四入口的选中块使用柔和阴影并避免在导航边界截断；展开全部与复习模式恢复独立按钮底色、边框与按压反馈，减少动态效果设置下关闭按压缩放。
