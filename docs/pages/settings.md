# 功能页：设置

## 入口
main.jsx 设置页签。
## 功能
答案绑定管理展开后，“答案匹配方式”列标题右侧提供说明图标。点击弹出答案脑图与直接子卡片的区别、子卡题目颜色要求及做题遮盖说明；通过“知道了”或 Esc 关闭，焦点返回说明入口。
设置顶栏下方悬浮四段圆角胶囊导航：答案配置、错题管理、个性设置、关于插件。导航仅占胶囊宽度，不铺满整行；页面内容在胶囊下方留出约 10px 间距。滑块使用快捷区筛选/全选的 `.45s cubic-bezier(.32,.72,0,1)` 位移动效，减少动态效果时取消过渡。
各设置块之间保留独立间距；工作台顶栏四个页签也使用同样缓动的滑块。

摘题工具绑定在任务开始后锁定，暂停时仍锁定，结束后恢复；关闭标题或答案摘录只禁用对应绑定。摘题会话进入、开始/暂停、退出时通知设置页更新；面板再次显示时独立获取绑定设置快照，不依赖错题索引版本变化，也不要求重载错题列表。

- 答案配置：当前脑图绑定答案、刷新索引、解绑；匹配规则位于绑定管理之前。展开“答案绑定管理”后，列说明只在顶部显示。匹配胶囊的“指定”半区展开答案脑图/子卡片子滑块；答案脑图名称可直接点击更换。题目筛选、刷新索引、删除使用图标按钮，筛选图标随展开状态形变为折叠图标；删除按钮第一次点击变为确认态，第二次点击删除。混合模式先查直接子卡，再查既有答案脑图规则。未选择题目颜色时，快捷区不会列题。
- 错题管理：批量标记所选卡片、刷新错题索引、导出错题；错题分类说明继续由 `MistakeLevelGuide` 展示，开发中的 AI 入口仍在本页。
- 个性设置：使用紫色图标主题，分为答题体验、操作与窗口、待复习设置。子卡片答案展示仅控制子卡答案的解除遮盖/答案窗口。答案遮盖设置点击后展开颜色与自定义图片；图片缩至最长边 512 像素后保存在本机设置中。开始做题时只解码一次自定义图片，各答案遮盖共用原生图片资源；图片加载失败时明确提示，且不会启动做题。待复习设置点击卡片评论自动折叠后使用 MarginNote 原生弹窗选择题目预览默认展开前 0–10 条评论；CardLink 渲染的各条评论可独立折叠，手动状态按卡片与评论序号记住。
- 关于插件：场景面板与整卡手写总开关（默认关闭、面板重新打开后切换、关闭后手写立即停用），版本、重置窗口、使用说明、检查更新；调试模式开启后显示日志和联通测试。

旧跨脑图绑定未存新字段时仍按原答案脑图规则运行。颜色按绑定关系保存；点击加号后在当前脑图选中一张题目卡片，再点击形变后的对勾读取其颜色，右侧取消图标可退出添加状态；已有颜色可逐项删除，整个流程不扫描学习集。学习集级旧绑定行显示“整个学习集”。“定位原题方式”通过原生选择弹窗在“仅定位”和“定位并聚焦”间切换。

绑定管理展开时只读取绑定元数据与已保存颜色，不扫描学习集卡片。
绑定操作只刷新匹配设置与绑定关系快照，不重建错题列表；绑定行按固定键排序，选色后保持原顺序。颜色选项显示色块并用高亮边框表示选中。MarginNote 插件接口仅提供卡片颜色编号，当前色块按内置调色板近似显示；自定义颜色模板的 RGB 值无法通过现有接口读取。
## 边界

更新确认按钮为「下载并安装」：将包解压并替换 CardLink 安装目录，保留旧目录用于失败恢复。原生插件菜单另有「从链接安装更新」「查看更新状态」，用于直链安装及对照运行/磁盘版本。文件替换不等同于热加载成功，参见[软件内更新测试](../design/in-app-update-test.md)。
- 个性设置的“卡片绑定手写显示”在“始终显示 / 按需显示”之间切换，默认按需显示；按需时用按钮显示或隐藏，避免干扰系统缩放；只控制绑定脑图手写的预览，不改变卡片内笔迹或 AI 发送策略。“错题本列表显示方式”在“始终显示 / 自动隐藏”之间切换，默认沿用固定列表。
- 「个性设置 → 待复习设置」提供「复习反馈」开关，不显示小字说明。默认开启，旧设置缺失 `reviewCompletionConfetti` 时仍视为开启；开启时只在复习队列结束时与原生结果弹窗一同触发；中途退出和做题结算不播放。关闭只停用烟花，不影响结果弹窗。系统减少动态效果优先于开关。该个人偏好以 `reviewCompletionConfetti: boolean` 保存在本机并跨重载保留；保存仅接受实际布尔值，非法值不覆盖当前选择，`setPersonalSetting` 对非法值拒绝写入。名称调整不改变开关语义或已有保存值。
- 调试模式提供日志、联通测试、调试安装包下载开关和更新状态查看（POST 测试已移除）。

批注问题排查时，先开启调试模式，再复现一次并导出日志。`annotation.trace` 标明请求编号、复习会话和宿主版本；`annotation.editor.request` 记录实际发送的版本、`commentIdPresent`（是否传入旧批注 ID）、连续做题模式和来源学习集；`annotation.editor.response` 记录宿主的 `continued`、批注 ID、接口版本及该 ID 是否存在于初始批注快照。缺失字段记为 `null`，不能据此推断新建成功。

自 b60 起，普通批注新建不使用官方判定，实际请求的 practice/advance 为 null；仍需场景允许 CardLink。`annotation.comments.snapshot/paper` 是读取或预读缓存中的批注身份与判定状态；`annotation.verdict.request/response` 对应官方反馈提交前状态和宿主响应。判定响应标为 `source: host-response`，不表示已额外独立回读验证；保存关闭后的实际读取另记快照。`annotation.closed` 同时记录宿主的 `hostSaved` 与插件实际接收的 `saved`，可判断误开旧纸的关闭事件是否被屏蔽。

每段日志携带 `trace` 与 `part=i/n`，同一事件的分段按序拼接后可恢复完整 JSON，避免网页与原生层的 400 字符限制截去关键字段。日志只选取身份、版本、状态、错因代码等协议字段，不输出批注正文、图片、笔迹或整份模板。调试模式关闭时沿用原有日志门控；日志失败不改变批注操作。
- 定位原题方式只影响复习模式外的定位操作；复习模式上下题始终进入焦点模式。取消原生选择弹窗不改变设置。
## 验收
每项动作有 HUD 反馈；调试开关即时生效。调试模式下新增「调试安装包下载」（默认关闭），启用后检查更新优先使用 2608204.xyz；退出调试模式自动关闭该项。调试区「查看更新状态」分别显示运行与磁盘版本。

## AI 发送与缓存（2026-09 重做，同日跟进为混合输入模型）

- 截图在首次使用时加载安装包本地 `web-dist/vendor/html2canvas.min.js`，工作台 bundle 不再内嵌副本。加载成功后复用，失败可重试；不依赖联网下载。PDF 导出窗口继续独立加载同一 vendor 文件。开发服务器提供对应本地资源，源码预览按 app.js 所在目录解析资源路径。

- 题目输入为混合模型：有可直接读取的题干文字（标题、分区标题和缺失媒体提示不计）时直接读取原生文字，不发生任何上传；含图片的题目才把去除手写后的整张卡片发给识别服务（MinerU 或 GLM-OCR）换取文字。图片题在未开启题目识别时明确拒绝发送（计入内容不可用）。
- 「手写内容」是统一开关（卡片内手写 + 脑图绑定手写）。手写永远不进入 OCR 截图；开启后，准备阶段把各手写元素单独捕获为图片存入快照，分析时随对应题目以服务图像字段直传给分析模型（单次最多 30 张，单图有体积上限）。手写开关参与策略指纹，切换后旧快照失效。
- 旧 `privacy.images`、「图片上传」选项已删除；旧「卡片内手写 / 脑图绑定手写 / 手写原图直传」任一开启都迁移为手写内容开启；旧 OCR 策略 "never" 迁移为识别关闭，其余策略等价于整卡识别。
- 新快照为 schemaVersion 3（策略指纹版本 4），记录来源内容与策略指纹；指纹不一致不能复用，须重新准备。原生文字直读题也会生成 provider 为 local 的快照（开启手写时含手写附件），未准备的文字题仍可分析但不附带手写。
- 预检统计最近更新的最多 300 道候选中可直接读取或快照仍有效的题数；容量限制发生在实际组装请求时，按完整题目装包，未发送的题目不能成为报告引用，缺失手写图片的数量写入报告 limitations。
- 取消、关闭 AI，或修改发送/识别/模型设置，会取消进行中的任务。已发出的请求无法撤回；返回结果被丢弃，不再写入报告或题目快照。

## 摘题设置与操作分类（2026-09-27）

答案配置新增独立「摘题」分组，包含「打开摘题模式」和点击展开的「摘题设置」。设置包含标题／题目／答案工具绑定、固定为子卡片的答案位置、是否摘录标题。先点击相应工具胶囊进入虚线「确认」状态，按提示在 MarginNote 顶部选择标题／题目／答案摘录工具，再次点击确认保存绑定；工具记录和标题开关跨重载保存。工具绑定在摘题开始后需结束再修改；摘录标题开关可随时切换，已有题目继续摘录答案，后续按新设置执行。标题开关保存为 JSON 布尔值，并兼容旧原生存储的 0/1。默认工具为标题文本摘录、题目和答案矩形摘录。

个性设置的「卡片绑定手写显示」「错题本列表显示方式」归入「操作与窗口」。摘题期间侧边按钮暂时停用，结束后开启。

「操作与窗口」新增「悬浮球默认展开模式」，点击在做题模式／摘题模式间切换并保存，旧设置默认做题模式。只影响没有进行中模式时点击悬浮球展开快捷区；已有做题或摘题会话优先继续当前模式。长按仍可临时切换模式，不改写默认设置。默认摘题模式仍需打开学习集文档，展开本身不会自动开始摘录。

工具绑定以「标题 | 工具名称」「题目 | 工具名称」「答案 | 工具名称」三个胶囊显示；未绑定灰色，已绑定强调蓝，等待确认时为虚线边框。首次点击仅提示选择对应工具，二次确认才记录；失败保留确认态，绑定栏不增加横线分隔。答案位置通过原生弹窗选择，目前只提供子卡片。标题开关与行右边缘对齐。摘题入口采用 SF Symbols 工具图标，说明为「快捷摘录题目与答案」。

标题格式包含原始标题、统一前缀＋标题、母卡标题＋标题、母卡内自动题号四项，使用原生选择弹窗；统一前缀通过 MN Utils 预填文本弹窗设置。前缀与标题以「 · 」连接；启用标题摘录时，统一前缀和母卡前缀在标题摘录完成后立即写入标题卡，不等待题目摘录，后续题目不重复添加。母卡类格式需绑定母卡，开始后禁用格式修改以免影响当前题目。自动题号在成功保存题目后递增，按学习集／母卡独立保存于本地，重新进入继续；首次建立续号位置时参考母卡已有直接子卡的「第N题」格式；之后按保存的下一题号码递增，手动改号会重设续号位置，不因已有更大编号跳号。手动修改的标题优先，不再套格式。旧配置默认原始标题，无历史批量改名。

摘题设置增加「摘录答案」开关，默认开启，旧配置沿用开启行为。关闭时禁用答案工具绑定、隐藏答案进度，保存题目后直接进入下一题，不创建答案子卡。摘题过程中可切换：若正在等待答案，关闭即结束本题，保留已保存题目并使待处理答案通知失效；重新开启只影响随后摘录流程，不补建旧题答案。


子卡片（含混合模式的子卡部分）需先绑定题目卡片颜色；未配置时绑定行显示提示及「绑定题目颜色」入口。查找答案无结果时先检查颜色，分别提示尚未绑定颜色或当前卡片颜色未加入绑定，再按正常无答案流程处理。


## 调试自动安装更新（2026-10-19）

调试功能新增「自动安装更新」，默认关闭；仅在调试模式中显示和生效。开关只保存设置；后续每次自动检查发现新版时，自动下载、直接安装，完成后提示完整退出并重启 MarginNote。开关本身不触发网络请求，也不绕过检查间隔。「调试安装包下载」独立控制是否优先获取网站测试版，测试网站更新时需先开启该项。后续自动检查沿用激活/回前台与 12 小时间隔。退出调试模式清除两个开关，重新进入不会自动恢复；下载期间退出或关闭自动安装，会在下载完成后跳过安装。

普通「检查插件更新」保留用户选择：「直接安装」完成后重启；「手动安装」选择保存位置后自行导入。安装后的运行/磁盘版本可在「查看更新状态」核对。


### 调试复习曲线

调试模式提供固定曲线 / FSRS 智能复习切换。调试关闭时隐藏入口，强制走固定曲线；保留 FSRS 选择与数据，重新开启调试后可继续。在「错题管理」原复习间隔区域可设置目标保持率 70%–97%（默认 90%）、最大间隔 1–36500 天及日期扰动。保持率不是解题正确率；不存在“温度”设置。详见 [复习页](review.md#fsrs-智能复习调试)。

## 全局题目颜色

在答案绑定管理展开后的表格上方，通过加号、选中脑图卡片、对勾确认添加全局颜色。全局颜色与各脑图局部颜色合并并去重，始终作用于全部绑定；全局和局部都未选时，答案脑图匹配默认全部卡片；子卡片和混合匹配仍要求颜色。点击全局颜色可移除，不改写各脑图原有局部配置。
# 2026-10-29 分类栏定位

设置分类栏放在设置页面内部，使用 Sticky 定位：滚动到顶部后停留在主导航下方，不再作为页面外的绝对定位悬浮层。工具栏保留原有分段选择、减弱动态和按钮可访问性语义。


## 场景模板转换（2.4.6-b75）

在「关于插件」开启「场景面板与批注手写」后，开关下方显示「模板转换」。展开后选择本机 `.mntemplate`，点击「转换并导出模板」，通过系统保存面板导出新模板。文件在本机处理，原文件不变。

按用户提供的 cardlink-website.zip 的 configure、methods、pack 实现，追加正式 CardLink 插件许可、卡片与文档答案／标错菜单，以及原生作答六错因配置。模板内部 ID 和名称保持原样，导出文件名添加“（转换后）”。保留原条目顺序、目录、布局、资源与已有插件文件；沿用参考代码对存储／deflate 条目的打包规则，不额外添加插件文件。已有 CardLink 的 tagPrefix 和其他配置字段保留，错因替换为当前六项；manifest 中登记 CardLink 依赖，按参考代码使用版本字段 2.4.6-b69，替换同 ID 的旧依赖项，不生成 folder 字段。该版本字段不是内嵌安装包。模板包最大 16 MB，解压内容最大 100 MB。模板不能补充宿主未提供的 API。

转换区提供[在线转换模板](https://aa284ce6291caf829.app.workbuddy.host/?sharecode=NW437CTJV6)，原生界面通过系统浏览器打开完整地址，保留 sharecode。

答案绑定的学习集和脑图选择共用纵向可搜索列表，约束在当前窗口内，长名称换行。取消选择或关闭插件不写入绑定。


b75 设置页文案按用户指定精简：场景功能标注软件 5.0.0 及以上、启用场景模式后重新打开窗口生效；上传区仅保留本机处理、16 MB 上限及超大文件的在线转换入口。仅改展示文案，底层能力检测不变。
