# liquid-glass-webgl 评估与回退历史

曾计划在 b71 把同一份未修改的 LiquidGlassRenderer 接入复习悬浮条、下拉框及信息框（见 [复习交互](review-queue-controls.md)）。该计划从未在当前工作树落地：源码里除尺寸弹窗外没有其他渲染器接入。2.4.8-b69 按用户要求移除该库后，此计划一并取消。

当前已无 WebGL 玻璃接入。2026-11-23（2.4.8-b69）按用户要求删除 `web/vendor/liquid-glass-webgl` 整份源码、专用接入 `web/src/lib/useSizeGlassFooter.js`、固定网格背景 `web/public/size-grid.svg` 及相关许可声明与上游逐字节校验测试；场景尺寸弹窗底部「恢复默认」「完成」恢复为项目现有普通 HTML 按钮和表单共享样式，不使用其他玻璃特效替代。此前 b53 曾在尺寸弹窗底部使用原版 WebGL 蓝色控件（染色强度 0.45），背景网格与两按钮共用整块画布，不采样工作台或原生脑图；上游文件固定在提交`0b90f9fc1cea8c7e59825f9aff1cbb96674b5b80`并逐字节校验。以下为旧版评估与回退历史，不代表当前版本。现行行为见[整卡手写与场景面板](../pages/handwrite.md)。

2026-10-14：按用户要求恢复2.4.5-b27，已撤出b28的WebGL实现、自定义背景采样、动画适配与AGPL组合发行构建。当前项目恢复MIT声明，使用原CSS材质；b28已发行的安装包和对应源码继续保留，其原许可不因回退而改变。

用户指定仓库为[martin65536/liquid-glass-webgl](https://github.com/martin65536/liquid-glass-webgl)，核查提交`0b90f9fc1cea8c7e59825f9aff1cbb96674b5b80`。上游采用AGPL v3，使用自绘背景与WebGL合成，不能直接装饰现有DOM，也不能解决宿主拖动优先级或读取原生脑图背景。

b28曾复用64份未修改的renderer/shader源码，并自行增加DOM近似重绘、控件适配和部分动画接线；它不是原项目界面与完整交互链路的照搬。该版本现已撤出当前生产源码。详细实现说明与源码保存在b28源码交付附件，相关发行说明为历史记录，不代表b27当前行为。

b27保留导航文字与数量自适应宽度、450/场景门限及此前手写接口；原生窗口拖动与角部缩放冲突仍未解决。当前没有WebGL背景采样，也没有b28新增的GPU装饰画布。
