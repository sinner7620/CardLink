# 摘题模式：选中卡片指定步骤（待实现方案）

本方案仅描述交互和数据行为，尚未实现。将“选中卡片后点标题／题目／答案”理解为：把已存在的所选卡片作为对应步骤的材料，复用当前摘题流程。

## 交互

在脑图单选一张卡片，点击进度条对应段直接处理；进度条文字、完成颜色及正常自动摘录继续保留。无选中或多选时 HUD 提示“请只选中一张卡片”，不写入。标题／答案开关关闭时不显示对应段，和现有进度条一致。每次操作成功后显示 HUD 和新的进度，失败保留原步骤与卡片。

| 点击 | 所选卡片用途 | 成功后 |
| --- | --- | --- |
| 标题 | 从摘录文字读取标题，标题为空时读取卡片标题；保存为本题待用标题。已有当前题目时更新该题标题 | 进入题目步骤；已有题目则继续答案步骤 |
| 题目 | 所选卡片成为本题题目，应用待用标题及现有标题格式、题号和题目颜色；有绑定母卡时采用现有题目归属规则 | 等待答案；答案关闭则完成本题 |
| 答案 | 所选卡片作为当前题目的答案，沿用现有答案命名及子卡片归属 | 完成本题，回到下一题起始步骤 |

标题卡属于用户已有材料，读取后保留，不按自动摘录临时标题卡的规则删除。选择题目本身不会清空其正文；选择答案保留其正文、图片与笔迹。标题格式默认沿用现有配置；重复点击同一卡片不重复计数或增加题号。

## 顺序和改配

允许跳过标题直接选题目，使用卡片原标题及现有标题格式。没有当前题目时点击答案，提示“请先指定题目”。本题已有题目且答案未完成时改配另一张题目，首次点击显示“将切换本题题目，再点题目确认”，再次点击同一卡片才切换；旧卡片保留。既有题目已完成时，指定另一题开启新一题。

将所选答案移动为当前题目的子卡片可能改变脑图结构：尚未归属于该题时首次点击明确显示“将移为〈题名〉的答案子卡，再点答案确认”，再次点击同一卡片执行；已经是当前题目子卡时直接处理。题目／答案不能同卡，也不能把当前题目的祖先移到题目下面。跨学习集卡片不处理。

## 与自动摘录共存

手动点击取一个固定的卡片 ID，不在异步写入时重新读取选择。写入期间进度段暂时禁用；使此前待处理摘录回调失效，成功后从新步骤恢复自动摘录。暂停时允许手动指定，完成后维持暂停；未开始时首次手动指定建立本题流程但不自动开始摘录。母卡、工具绑定、标题及答案开关沿用当前设置。

## 实现边界与验收

计划在原生进度条各段叠加点击按钮，并把自动摘录与手动指定的写入流程抽成共享步骤；材料来源标识决定标题卡是否可删除，既有标题卡永远保留。改配确认绑定步骤／所选 ID／当前题 ID，任何选择、步骤或会话变化取消确认。

行为测试覆盖读标题、无标题直选题、无题目选答案、暂停处理、重复点击、旧回调失效、题号只递增一次、改配失败不推进。真机验收单选读取、子卡移动及数据保留、脑图刷新、连续摘录与手动操作交错。实现前需按本方案核对 MarginNote 的所选卡片与原生移动接口。
