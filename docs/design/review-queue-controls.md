# 复习悬浮条与连续队列批注方案

状态：2026-10-19，b75 已实现（连续批注暂不加入），等待 MarginNote 真机验收。

## 悬浮条

在退出按钮右侧增加展开按钮，展开为长条，显示当前题目来源：学习集 → 脑图 → 各级父节点。每一级点击后展出下拉框，列出本次复习队列中属于该节点子树的题目，选择后使用现有跨学习集定位流程。按稳定节点 ID 筛选，不能使用标题判等；进入复习时从原题祖先节点读取 ID，按根到父节点顺序展示，子脑图以上的祖先不重复显示。来源较长时横向滚动；拖动左侧整组操作区（包括题号、按钮及空隙）可以移动悬浮条，来源区域独立横向滚动。

点击下一题先展开「不会／不熟／掌握／跳过」。成功保存对应状态后再切下一题，提交期间防重复点击；失败保留当前题并显示错误。跳过仅移动到下一题，不写入等级、历史或完成时间。最后一题仍应允许标记，完成后提示队列结束。

如果题目今日已经完成复习，下一题直接前进。以持久化的复习完成记录和本地自然日判定，不能使用“曾打开”或“曾访问”；每次下一题读取持久化 lastReviewedAt，队列同时保留本次保存返回的时间。悬浮条直接提交当前队列题目，不依赖答案卡片是否打开。

## 连续队列批注

提供的「刷题·卡片」模板 ports.js 调用 POST /notes/{noteid}/annotation-editor，携带 expectedRevision、practice.topic、advance（next 或 finish）和 confirm。controller.js 在 practice 事件后刷新当前题目，核对会话与模式，寻找后续尚未打开的题目，再请求打开编辑器；它不是简单循环点击下一张。

按用户最新要求，本版不接入连续批注，不增加队列入口、会话或 advance 请求。保留上述调研供以后使用，现有普通单卡批注不变。

## 普通悬浮条与动画

恢复白色原生胶囊，不再加载复习条的 WebGL 引擎、折射纹理或按压材质。删除详情按钮、信息面板及事件入口。其他模块已有的 WebGL 功能不在本次范围。

收起宽度 180，高度 40；来源采用 13 号字，按文字长度计算紧凑宽度，逐级用 › 连接，去掉重复下拉标记，逐级点击仍可展开。长路径横向滚动。展开/收起通过原生 0.2 秒 frame 和透明度动画完成；下拉框同样动画开合。减少动态效果时直接切换。动画回调仅清理自己持有的旧视图，连续开合不删除新面板。

## 验收

桌面行为测试覆盖同名祖先过滤、跨学习集跳转、今日完成去重与跨日、保存失败不跳题、连续点击只提交一次、末题标记、动画开合、快速连续点击及减少动态效果。真机单独验证展开布局与下拉框可点、四种状态落盘、跨学习集切换、关闭后无残留事件、原生动画流畅度和来源可读性。

缩放复测需在原视频相同内容上连续双指放大缩小、多次抬指重捏，并检查单指滚动和锚点。本轮测试只证明 touch/gesture 混合事件不再重设共享基准；页面原生缩放是否仍参与，以及是否解释录像全部跳变，仍待真机验证。


## b73：今日进度和定位下拉

题号居中，灰色外圈从 12 点顺时针按今日已有反馈的题数 / 队列总题数填充，无装饰圆点。跳过、查看和昨日反馈不计入今日完成，重复反馈不会增加分母或重复计数；全部完成时先显示满环再结束。序号选择列表在已完成项后标 ✅；来源队列已完成使用规范绿色 UI_COLORS.level2 的 20% 底色，当前题使用规范强调色 UI_COLORS.accent 的 20% 底色（当前优先），文字不变。背景统一白色。

来源文字两侧仅保留共 6px，递进箭头宽 10px；下拉左边缘跟随点击按钮（包含来源横向滚动偏移），超出屏幕时夹紧。评分下拉跟随下一题按钮。列表宽度按 14 号文字估算并加内边距，最低 64、最高 360，受屏幕宽度限制；超长标题尾部截断。拖动时同步计算定位，不重置到悬浮条左端。


## b75：来源子树分组
在所选来源节点下，将题目按剩余祖先路径逐级分组，显示灰色、不可点击的节点名称；标题下方列出该节点直属题目，再展开后代分组。兄弟组按首次出现顺序排列，同名不同 ID 不合并。题目保留原队列索引和完成底色，灰标题不占复习题数。逐级缩进最多 50px，防止深层路径挤掉题目；长列表滚动、长名称尾部截断。
