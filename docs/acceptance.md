# 验收标准（按功能页）
使用方式：按 [验证流程](workflow.md) 选择受影响功能；本清单不要求每轮全部执行。条目是历史功能验收参考，涉及旧行为时先核对本轮需求。

安装包真机验收前置：完全退出并重启 MarginNote 4；设置页确认版本号；调试模式可开合。文档检查、纯函数测试和浏览器预览不需要该前置。

## 面板壳
- 开/关面板 → 工具栏图标高亮同步（三条关闭/隐藏路径 + 恢复路径）
- 切换笔记本 → 面板按记忆恢复；滚动位置不跳变；缩放不抖动
## 错题本
- 搜索/等级/分类筛选实时生效；批量标记/改级/取消后队列与徽标实时更新
- 取消错题后不复活（标签已清 + 冷启动验证）
- 详情：原题/答案/手写三形态；定位原题跨学习集成功
## 总览
- 今日到期数 = 待复习页今日数 = 顶部徽标数（日历口径）
- 来源分布不含纯答案学习集
## 待复习
- 切页即时（不随到期数线性变慢）
- 复测评价后倒计时/历史/队列实时更新；完整原题默认收起、展开即载
## 设置
- 绑定/解绑对称：解除后立即查答案不命中旧答案集（scoped 两态）
- 刷新错题分类索引：HUD 含「从标签新收编 N 道」；重复导出目录不累积
- 联通测试显示测试1/2/3（无网址）；导出运行日志含桥接观测与分段耗时
## 导出
- 范围/筛选/方式/搜索组合计数实时正确；失效记录排除并明示
- 手动自选：搜索/仅看已选；缩小筛选不丢已选
- PDF：四种密度 × 三种答案位置页序正确；四边 56pt 边距；预览所见即所得
- 大范围导出不超时（任务状态实时更新）；取消任务生效；MD 导出目录保留最近 5 份
## 更新与遥测
- 检查更新：坏包被拦（体积校验）；断网失败不写节流；Gitee 回退可用
- 挂起状态零外呼
## 标签与恢复
- 四代标签方案识别；取消错题的标签清理后恢复扫描不再收编
- 标签恢复仅随「刷新错题分类索引」发生（无自动弹窗）
